# Crosspect — сводка для продолжения работы

Обновлено: 7 ноября 2026 (ночь). Актуальный код формы: `crosspect/sermon.html` (рядом в базе знаний проекта). Настройки и свои переводы — в репозитории GitHub `crosspect-app/crosspect` (копия настроек: `crosspect/crosspect-data/`).

## Что это
Crosspect (раньше «форма проповеди», файл `sermon.html`) — браузерный инструмент церкви «Слово веры» (Познань). Проповедник собирает конспект проповеди из блоков в одном формате, вместо зоопарка из Telegram, Word, Google Диска и PPTX. Виталий по нему делает слайды (Canva / Holyrics). Оператор на служении открывает конспект с телефона.

Название: **Crosspect** = Cross (крест) + -spect («смотреть»: inspect, aspect, prospect). По-русски созвучно со словом «конспект».

Решено: форма в итоге будет **обязательной** для всех проповедников. Серию проповедей пока не рассматриваем.

## Текущий формат (MVP)
- Один самодостаточный HTML-файл. Сервера и базы нет.
- «Сохранить» (Ctrl+S) скачивает новый HTML с проповедью внутри (`<script id="sermon-data" type="application/json">`). «Открыть» загружает такой файл, понимает и `.json`.
- Черновик автоматически сохраняется в localStorage браузера.
- Два режима: «Редактор» и «Просмотр» (для оператора): переключатель «Слайды + текст» / «Только слайды», размер шрифта A−/A+, кнопка копирования текста слайда.
- Интерфейс на Unbounded; для греческого и других алфавитов — Inter. Тёмная и светлая тема по системе.
- Интернет нужен для шрифтов, настроек и текстов Библии.

## Шапка
Дата (по умолчанию ближайшее воскресенье) и проповедник из списка «Фамилия Имя» (список приходит из настроек; есть встроенный запасной). Есть пункт «Другой — ввести вручную».

## Блоки
- В окне «Что добавить?» первым стоит «Текст проповеди», дальше типы слайдов.
- **Свернуть / развернуть** блок: кнопка со стрелками или клик по заголовку. Свёрнутый блок — одна строка с кратким содержанием. В меню «⋯» — «Свернуть все блоки» / «Развернуть все блоки». Состояние (`collapsed`) сохраняется в проповеди.

Типы:
1. **Место Писания.** Один слайд, на нём несколько элементов в любом порядке (места Писания в любых переводах, текст). Выбор: перевод → книга → глава → стихи (кнопки, Shift+клик — диапазон, поле «1-3, 5», «Вся глава», «Сбросить»). Текст стиха можно править; ↺ возвращает исходный. Ручной режим «Ввести текст вручную». «Продолжить на новом слайде».
2. **Тезис.** По умолчанию заглавными (переключатель «Заглавными буквами»). Предпросмотр, текст по центру, базовый размер 72.
3. **Цитата.** Текст + автор. Предпросмотр: текст по центру, автор в правом нижнем углу (имя обычным, фамилия жирным, всё заглавными; источник после запятой — мелко второй строкой). Размер текста: шаг −/+ по 1%, от 100% до 85%, где 100% = на 10% крупнее имени автора (автор 52 px, текст 57,2 px). Переключатель стоит в строке подписи «Цитата».
4. **Картинка**: «Найди сам» / «Пришлю отдельно».
5. **Видео**: «Ссылка» / «Пришлю отдельно», тайминг, комментарий.
6. **Свободный слайд**.
7. **Текст проповеди**: на экран не выводится, галочка «Здесь вывести заставку».
- Лимиты (меню «⋯» → «Лимиты»): Писание — до какого % уменьшать текст (80%); тезис 220 и цитата 300 символов. Превышение подсвечивается жёлтым.

## Оформление текста
Панель: **Ж**, **К**, Ч, маркер, «Убрать оформление». Ж и К — переключатели, подсвечиваются по выделению; Ж + К вместе = жирный курсив. У Unbounded нет настоящего курсива — браузер наклоняет буквы, в JPEG будет так же. При вставке убираются мягкие переносы (U+00AD, приходят с azbyka.ru).

## Переводы Библии
- Выбор перевода — кнопка («RU Синодальный») с панелью: сначала видны только языки (Русский, Українська, Polski, English) и отдельно «Свой перевод»; у языка справа — его перевод по умолчанию (или выбранный). Нажал язык — раскрылись версии, первая помечена «по умолчанию». Поиск по языку и по переводу (название, сокращение, псевдонимы; польские буквы можно не набирать), при поиске нужные языки раскрываются сами. В списке книг — только книги выбранного перевода.
- Перевод по умолчанию = первый перевод языка в `config.json`: Синодальный, Огієнко, Biblia Warszawska, NIV.
- Список приходит из настроек (`data/config.json`); встроенный запасной — 22 перевода.
- Сейчас в настройках (23):
  - Русский: Синодальный (СП), НРП, под ред. Кулакова / Заокский (BTI), СРП РБО — только НЗ («Радостная весть»), Переводы Десницкого (Десн, отдельные книги), Современный перевод Библейской лиги (RSP), под ред. еп. Кассиана (НЗ).
  - Українська: Огієнко, Турконяк 2011, Хоменко, Сучасною мовою, НПУ (НЗ).
  - Polski: Biblia Warszawska, Uwspółcześniona Biblia Gdańska, Biblia Gdańska, Nowa Biblia Gdańska, EIB 2018, Słowo Życia (NT), NPD (NT).
  - English: NIV, KJV, NKJV, ESV.
- **«Свой перевод»** встроен в форму (в настройках его нет): всё вручную — Книга (подсказки названий), Глава, Стихи («2-4, 8» → строки стихов создаются сами, набранный текст сохраняется), Название перевода, текст каждого стиха. При переключении «из Библии ↔ Свой» книга, глава и номера переносятся (книга узнаётся по названию).
- Убраны по решению: Восточный перевод, Куліш і Пулюй, RST 1900 (дореформенный Синодальный).
- Источник: Beblia (`raw.githubusercontent.com/Beblia/Holy-Bible-XML-Format/master/`), свои файлы — из репозитория. Форма читает форматы Beblia и Zefania (как у Holyrics).
- Чистка текста: сноски `[60]`, метки `[1-6а]`, ударения, мягкие переносы, пропущенные пробелы после знаков, `***` у объединённых стихов. Пустой стих: «В этом переводе стих объединён с соседним».
- Нумерация — как в самом переводе. В польских, английских и части украинских нумерация псалмов еврейская.
- У Кулакова в Псалмах надписание склеено с первым стихом («Псалом Давида ГОСПОДЬ…») — пока правится руками.
- **СРП Ветхий Завет** — только в файле Виталия (Zefania, из Holyrics), публично не выкладываем (авторское право РБО). Полный СРП — после облачной версии с входом.
- **Десницкий**: сделан из модуля MyBible «Десн» (ph4.ru), 48 книг (нет Пятикнижия кроме Судей, Псалтири, Притчей, Иеремии, Даниила, Деяний, Откровения). Условия автора: некоммерческое использование и цитирование с указанием авторства, изменять текст нельзя → в инструкции для проповедников сказать, что формулировки перевода не переписывают.
- Не проверено: польские и украинские названия книг; нужна ли запятая в польской ссылке («Jana 3,16»).

## Настройки из репозитория
- Репозиторий: **github.com/crosspect-app/crosspect** (организация crosspect-app, публичный, GPL-3.0 для кода; у текстов Библии свои условия). Приложение Claude на GitHub установлено — Claude может коммитить сам.
- Структура: `README.md`, `data/config.json`, `data/README.md`, `data/bibles/RussianDesnitskyBible.xml`.
- Форма читает `https://raw.githubusercontent.com/crosspect-app/crosspect/main/data/config.json` (константа `CONFIG_URL_DEFAULT`). Последняя копия кешируется в localStorage; если файл недоступен — встроенные списки.
- `config.json`: `version`, `bibleBase`, `scriptureFooter` (шаблон подписи перевода на слайде, по умолчанию `* {name}`), `groups`, `translations` (`id`, `abbr`, `label`, `tr` — подпись у оператора, `slide` — подпись на слайде, `file` или `url`, `books`, `note`, `alias`), `preachers`, `limits`. **`id` переводов не менять** — по ним сохранённые проповеди помнят перевод. Перевод, который убрали из настроек, в старой проповеди превращается в ручной ввод (текст сохраняется).
- Меню «⋯» → «Источник настроек»: ссылка, загруженная версия, «Проверить и применить», «По умолчанию».
- Позже туда же: фоны и темы слайдов (картинки с GitHub годятся для сборки JPEG), шаблоны.
- Google Диск отвергли: браузер не может читать файлы Диска без ключа Google API.

## Слайды (предпросмотр = будущий JPEG)
- Кадр 1920×1080, раскладывается в полном размере и только масштабируется.
- Слои: чёрная основа; кремовая рамка #ecdfcf с зерном (отступ 14, радиус 34); панель (отступ 44, радиус 8) с градиентом «Ember». Тема «Dusk» — пока только в шаблоне `scripture-slide.html`.
- Текст #ecdfcf, Unbounded. Маркер — цвет #ffde59.
- Писание: стихи Regular, ссылка и номера Bold, по центру; расстояние между элементами 0,85 em; подгонка по отступам сверху/снизу (бинарный поиск).
- **Подпись перевода** внизу слайда Писания: «* Синодальный перевод» (по шаблону `scriptureFooter` и полю `slide`), 90% от базового размера (43,2 px), по центру, низ на 96 px от края кадра. Тумблер «Показывать перевод на слайде» в блоке, по умолчанию включён. Если подпись есть, текст подгоняется не до края панели, а до подписи с запасом 48 px (`SL.trGap`). Несколько разных переводов на слайде — через « · »; у «Своего» — поле «Название перевода».
- Тезис и цитата: область текста — отступы 170 по бокам, 150 сверху/снизу (у цитаты снизу 250 под автора), текст по центру, при переполнении уменьшается.
- Переносы: короткие слова (1–2 буквы и без/для/над/под/при/про/что/как/или/ибо/изо/обо/ото/чем) приклеиваются к следующему; же/ли/бы — к предыдущему; одно слово на последней строке не остаётся. Работает во всех типах слайдов.

## Как продолжать
- Новый чат начинать **внутри проекта «SWP Church & Holyrics»** (там эта сводка в базе знаний) или попросить подключить репозиторий `crosspect-app/crosspect` — копия сводки лежит в `docs/handoff.md`.
- Актуальный код формы — в базе знаний проекта (`crosspect/sermon.html`).
- Лимит: длинный чат дорогой — лучше короткие чаты со сводкой; Opus 5.5, высокий уровень для сложного, средний для мелких правок.

## Следующие шаги (по пользе)
1. **Быстрый ввод ссылки**: поле, куда вписать или вставить «Иак 1:2-4» или целый список → форма сама создаёт слайды (нужен словарь сокращений и форматов из анализа выше).
2. **Работа с готовым текстом**: вставить весь текст проповеди в один блок, «Слайд здесь» разрезает текст; найденные ссылки подсвечиваются с кнопкой «Сделать слайдом».
3. **Фото с подписью** (имя, годы жизни) и **цитата с портретом** (портрет на 1/3 слева/справа, сепия или другой цветокор, обводка, текст на 2/3). Вырезка фона — вручную или через Canva (коннектор Canva подключён, тариф Pro); проверить автозаполнение шаблонов.
4. **Блок «Слово»** для греческих/еврейских слов: оригинал, транслитерация, значение.
5. Кнопка «Скачать слайды» (JPEG 1920×1080), выбор темы (Ember / Dusk / новые) — темы из репозитория.
6. Положить саму форму в репозиторий и включить GitHub Pages: проповедники открывают по ссылке, всегда свежая версия.
7. Логотип: CROS✝SPECT с крестом-курсором, значок «слайд с крестом» — не утверждён; потом название и значок в шапку, переименовать файл в `crosspect.html`.
8. Позже: облачная версия (Firebase, вход через Google) — закрытые переводы (СРП ВЗ), статусы, ссылка для оператора; помощник на церковном ПК для Holyrics (`AddToPlaylist` в API Server).
9. Короткая инструкция для проповедников и пример заполненной проповеди.

## Решения и предпочтения
- Дизайну нейросетей для PPTX не доверяем. Целевой вывод — JPEG.
- Медиафайлы проповедник присылает отдельно, подписывая номером слайда.
- Обновлённый код присылать **целиком**, а не фрагментами.
- Тексты для пользователей — естественный русский, без канцелярита.

## Устройство кода (sermon.html)
- Модель: `state = { meta:{title,date,preacher}, settings:{minScale,limitThesis,limitQuote,lang}, blocks:[…] }`. Блок Писания: `{type:'scripture', collapsed, showTr, items:[{kind:'scripture', lang, book, chapter, sel:[…], verses:[{num,text,orig}], ref, translation} | {kind:'scripture', manual:true, mBook, mChapter, mVerses, translation, ref, verses:[{num,text}]} | {kind:'text', html, align}]}`. Тезис `{text, caps}`, цитата `{text, author, scale}`.
- Переводы: `LANGS` (ключ = id), `TR_GROUPS`, `SLIDE_NAMES`, `TR_FOOTER`, `OWN`; `loadBible` (Beblia и Zefania, `verseText`, `cleanVerse`), `syncVerses`, `trPicker` / `openTrPanel` / `trTitle`; ручной ввод — `partEditor`, `manualRef`, `splitManualRef`, `toManual` / `fromManual`, `findBook`, `syncManualVerses`; подпись — `slideTrName`, `trFooterText`.
- Настройки: `CONFIG_URL_DEFAULT`, `applyConfig`, `loadCachedConfig`, `fetchConfig`, `openConfig`.
- Слайды: `slideEl`, `slideHTML` (Писание), `boxHTML` / `authorHTML` / `layoutBox` (тезис, цитата), `layoutAt`, `fitSlide`, `BASE`, `QSCALE` / `quoteStepper`, `typoText` / `fixOrphan`.
- Прочее: `blockSummary`, `toggleFold` / `foldAll`, `syncFmt`, `normalize` / `normItem` (перевод старых форматов).
- Проверять удобно Playwright: в рабочей среде есть Chromium; файлы Beblia можно подставлять через `page.route`.
