Перенесено из `STATUS.md` 13 ноября 2026 (этап 9.4). Решения Виталия и предпочтения, которые должны пережить переписывание `STATUS.md`. Новые — сверху.

## Анализ того, как присылают сейчас
Образцы: Telegram-текст, несколько docx и Google Документ, список ссылок сообщением, Telegram Евгения Шоды (каждое сообщение ≈ слайд). Ссылки пишут по-разному: «Иак.1:2-4», «3Цар 18:36-38», «1 Коринфянам, 1 глава, 10–12 стихи», «Осия 11:1-4/8-9», «1Кор 13,4», «Марка» без «От». Часто приводят свой текст стиха — он главнее ссылки. Бывают фото людей с историями, греческие слова, двуязычные слайды, просьбы оператору.

## Решения и предпочтения
- Дизайну нейросетей не доверяем; целевой вывод — JPEG, собранный из шаблона.
- Медиафайлы проповедник присылает отдельно, подписывая номером слайда.
- Telegraph для оператора отвергнут; сжатые данные в ссылке — тоже (лимит Telegram 4096 символов). Google Диск для настроек отвергнут (нужен ключ API).
- Код Виталию присылать целиком, не фрагментами. Тексты для пользователей — естественный русский, без канцелярита.
- Вход обязателен (этап 8): «Продолжить без входа» и файлы убраны, старые черновики из браузера не переносятся.
- Облако: Firebase (вход Google + Firestore, без карты) + GitHub Pages; загрузки картинок не будет (отменено 13 ноября 2026). Роли админ / редактор / проповедник, пространства для разных церквей. Подробно — `docs/PLAN.md`.
- Права (этап 4, с правками 7.3 и 8): админ всей формы (`admins/{почта}`, пишет только служебный скрипт) видит все пространства и может в них всё; участников добавляет и меняет только он; роль `admin` у участника — просто редактор. Автор (`preacher`) правит только свои проповеди и только пока они не «У редактора», сам ставит лишь «Черновик» и «Готов к вёрстке», удаляет только свой черновик; «У редактора» — редактор. Админ не может снять админа с себя. Новые пространства заводит только служебный скрипт — чтобы посторонние не заняли место в бесплатной базе (открыть для других церквей — потом, одним правилом). Ссылку для оператора делает тот, кто может править проповедь; открыть её может кто угодно по ключу.
- Плотность текста как в Canva — основная для всех текстов (подтвердить на проекторе).
- Заметка оператору остаётся отдельным блоком — узкий жёлтый мини-слайд в ленте.
- 13 ноября 2026 (этап 9.7, решения Claude в рамках решений Виталия — поправить, если не так): копия в другое пространство — с тем же названием, без «(копия)»; копию в историю делает и Ctrl+S, не только «Сохранить»; «Сделать копию» при открытой правке сначала сохраняет оригинал; цвет «Презентация готова» — фиолетовый; в окне «История» версия показана текстом (как вид «Текст»), без миниатюр.
