# crosspect-backup

Приватный репозиторий Crosspect: резервные копии базы и служебные действия. Публичный код — [crosspect-app/crosspect](https://github.com/crosspect-app/crosspect), скрипты — в его папке `cloud/scripts/`.

- `data/` — копия базы: один документ — один файл JSON. Делается каждую ночь (Actions → «Резервная копия»); коммит появляется, только если что-то изменилось. Любая прошлая копия — в истории репозитория.
- Actions → «Восстановить из копии» — вернуть базу к копии. Перед восстановлением сам делает свежую копию (её можно скачать со страницы запуска 30 дней).
- Actions → «Пространства» — список пространств и участников, добавить участника или сменить роль, удалить участника, завести новое пространство.

Нужен секрет `FIREBASE_SERVICE_ACCOUNT` (Settings → Secrets and variables → Actions) — тот же ключ, что в публичном репозитории.
