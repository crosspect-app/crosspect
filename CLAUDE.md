# Правила для Claude в репозитории Crosspect

- Сначала прочитай `STATUS.md` (что есть и что дальше) и `ARCHITECTURE.md` (как устроен код).
- Пользователь — Виталий, не программист. Код пишет Claude. Решения по продукту и текстам — за Виталием: перед изменением поведения или текстов, которые увидят проповедники, согласовать.
- Работа идёт по этапам из `docs/PLAN.md`; в начале беседы найди в `STATUS.md` текущий этап, в конце — отметь его и коммить. Модель для этапа указана в плане: если беседа идёт на другой, скажи об этом Виталию в первом ответе.
- Форма — один файл `sermon.html` без сборки и сторонних библиотек (до этапа 1; дальше — модули без сборки, единственная библиотека — Firebase SDK с CDN).
- Старые файлы проповедей должны открываться: любые изменения модели — через `normalize` / `normItem`.
- Перед коммитом проверять в Playwright (см. `ARCHITECTURE.md`): редактор, предпросмотр, JPEG, а при изменении печати — PDF.
- Если Виталий вставляет код сам — присылать файл целиком, не фрагменты.
- Тексты для пользователей — естественный русский, без канцелярита и кальки; каждое утверждение — правда.
- После заметных изменений обновлять `STATUS.md` (раздел «Что умеет», «История», «Следующие шаги»).
- Коммиты на русском, коротко, что изменилось для пользователя.
