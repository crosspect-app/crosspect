# Фотобанк: пачки фото из беседы «Фотобанк»

С этапа 10.5.2 фотобанк живёт в облаке (`bankPeople`, `bankPhotos`, `bankFiles`), а одиночные фото Виталий загружает сам в форме (окно «Фотобанк»). Эта папка — для пачек фото, которые готовит Claude в беседе «Фотобанк» проекта claude.ai (Sonnet, низкое усилие): `tools/author_photo.py` кладёт сюда фото, workflow «Фотобанк» в `crosspect-backup` переносит в базу всё, чего там ещё нет.

## Как добавить фото (для Claude)

1. Виталий присылает фото, названные именем человека (`Клайв Льюис.png`, можно несколько сразу). Прозрачный PNG — фото «без фона», обычное фото — «с фоном».
2. Клонировать репозиторий, положить файлы во временную папку вне репозитория.
3. Посмотреть на картинку без фона: куда смотрит человек — `right`, `left` (развернуть) или `front` (анфас).
4. Запустить:
   ```
   python3 tools/author_photo.py /tmp/x.png --id lewis-cs --first Клайв --last Льюис \
     --caption "писатель · 1898–1963" --aliases "К. С. Льюис; C. S. Lewis" --faces left --source "Wikimedia Commons, общественное достояние"
   python3 tools/author_photo.py /tmp/y.jpg --id lewis-cs-2 --person lewis-cs --kind bg --source "…"
   ```
   - `--id` — id фото: фамилия латиницей, при совпадении — с именем (`elliot-jim`, `elliot-elisabeth`); второе фото того же человека — с номером (`lewis-cs-2`) и `--person lewis-cs`.
   - `--first` и `--last` — как на слайде: фамилия жирным. «Корри» + «тен Бум», «Мартин Лютер» + «Кинг», «Августин» + «Блаженный», «Мать» + «Тереза». У второго фото того же человека можно не писать.
   - `--caption` — подпись под автором на слайде: описание и годы жизни через « · » («физик · 1643–1727», «писатель · род. 1955»), без скобок. Годы проверить по источникам.
   - `--aliases` — другие написания (инициалы, латиница, полное имя): по ним работает поиск.
   - `--kind bg` — фото с фоном (не отражается, `--faces` не нужен).
   - `--source` — откуда фото. Не сказано — спросить. Где имя, где фамилия, если неочевидно, — спросить.
   - Человек, заведённый в форме, у скрипта под другим id: если он уже есть в окне «Фотобанк», лучше попросить Виталия загрузить фото туда самому, иначе появится второй человек с тем же именем.
5. `python3 -m pytest tests/test_stage105.py tests/test_stage1052.py -q`, коммит «Фотобанк: Клайв Льюис», отправить в `main`.
6. `crosspect-backup` → Actions → «Фотобанк» → Run workflow (`upload`). Можно сначала с «Только проверить». Ответ Виталию — одна строка.

Описание человека, которого уже правили в форме, скрипт не меняет; фото, которое уже есть в базе, — тоже (кроме «Заменить»). Вид фото по умолчанию Виталий задаёт сам в форме.

## Что в `authors.json`

Список фото: `id`, `person` (id человека), `first`, `last`, `caption`, `aliases` (у всех фото человека одинаковые), `kind` (`cut` — без фона, `bg` — с фоном), `file` (`<id>.webp`), `thumb` (`<id>.thumb.webp`, 160 px), `w` и `h`, `faces` (у `cut`: `right` — смотрит вправо, `front` — анфас), `source`, `added`. Без фона — WebP с прозрачностью, поля обрезаны, не выше 1600 px; с фоном — не больше 2400 px по длинной стороне; не больше 900 КБ.

У фото современных авторов почти всегда есть правообладатель: источник записывать обязательно.
