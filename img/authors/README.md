# Фотобанк авторов цитат

Фото для цитат «Текст слева / справа» (этап 10.5). В форме загрузки картинок нет: фото добавляет Claude в беседе «Фотобанк» проекта claude.ai (Sonnet, низкое усилие).

## Как добавить фото (для Claude)

1. Виталий присылает прозрачный PNG, названный именем автора (`Клайв Льюис.png`, можно несколько сразу).
2. Клонировать репозиторий, положить PNG во временную папку вне репозитория.
3. Посмотреть на картинку: куда смотрит человек — `right`, `left` (развернуть) или `front` (анфас).
4. Запустить:
   ```
   python3 tools/author_photo.py /tmp/x.png --id lewis-cs --first Клайв --last Льюис \
     --caption "писатель · 1898–1963" --aliases "К. С. Льюис; C. S. Lewis" --faces left --source "Wikimedia Commons, общественное достояние"
   ```
   - `--id` — фамилия латиницей, при совпадении — с именем: `elliot-jim`, `elliot-elisabeth`.
   - `--first` и `--last` — как на слайде: фамилия жирным. «Корри» + «тен Бум», «Мартин Лютер» + «Кинг», «Августин» + «Блаженный», «Мать» + «Тереза».
   - `--caption` — подпись под автором на слайде: описание и годы жизни через « · » («физик · 1643–1727», «писатель · род. 1955»), без скобок. Годы проверить по источникам.
   - `--aliases` — другие написания (инициалы, латиница, полное имя): по ним работает поиск.
   - `--source` — откуда фото. Не сказано — спросить. Где имя, где фамилия, если неочевидно, — спросить.
5. `python3 -m pytest tests/test_stage105.py -q`, коммит «Фотобанк: Клайв Льюис», отправить в `main`. Ответ Виталию — одна строка.

Через пару минут после выкладки автор появится в подсказках под «Имя» и «Фамилия» у цитаты. Вид фото по умолчанию Виталий задаёт сам в форме.

## Что в `authors.json`

Список записей: `id`, `first`, `last`, `caption` (подпись), `aliases`, `file` (`<id>.webp`), `w` и `h` (размер в px), `faces` (`right` — смотрит вправо, `front` — анфас), `source`, `added` (дата). Файлы — WebP с прозрачностью, высота 1600 px, прозрачные поля обрезаны.

У фото современных авторов почти всегда есть правообладатель: источник записывать обязательно.

Правки описаний из окна «Фотобанк» в форме (только админ) и вид фото по умолчанию лежат в облаке (`authors/{id}`) и показываются поверх `authors.json`; сам файл они не меняют.
