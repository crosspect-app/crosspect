# crosspect-data

Настройки и файлы для формы **Crosspect** церкви «Слово веры» (Познань). Форма при запуске читает `config.json` отсюда. Если файл недоступен, форма работает на встроенных списках.

Менять что-то в форме не нужно: достаточно поправить файлы здесь. Изменения подхватываются при следующем открытии формы.

## Что здесь лежит

| Файл | Что это |
|---|---|
| `config.json` | Переводы Библии, проповедники, лимиты |
| `bibles/` | Переводы, которых нет в общем источнике Beblia |

## config.json

- `version` — меняйте при каждой правке, например `2026-11-20.1`. Её видно в форме: «⋯» → «Источник настроек».
- `bibleBase` — откуда брать переводы, у которых указано поле `file` (по умолчанию открытый источник Beblia, в том же формате, что у Holyrics).
- `scriptureFooter` — как подписывать перевод внизу слайда Писания. `{name}` заменяется на название перевода (поле `slide`). По умолчанию `* {name}` → «* Синодальный перевод».
- `groups` — языки в списке выбора перевода и их порядок. **Первый перевод каждого языка в списке `translations` — перевод по умолчанию.**
- `translations` — переводы, в том порядке, в каком они показываются:
  - `id` — короткий код. **Не меняйте его у существующих переводов**: по нему сохранённые проповеди помнят, какой перевод выбран;
  - `abbr` — сокращение (НРП, СРП, UBG);
  - `label` — название в списке выбора;
  - `tr` — как перевод подписан у оператора;
  - `slide` — как перевод подписан на слайде (например «Синодальный перевод»);
  - `file` — имя файла в Beblia, или `url` — ссылка на свой файл (можно относительную, например `bibles/RussianDesnitskyBible.xml`);
  - `books` — язык названий книг: `ru`, `uk`, `pl`, `en`;
  - `note` — пометка в списке, например «Новый Завет»;
  - `alias` — дополнительные слова для поиска.
- `preachers` — проповедники в виде «Фамилия Имя». Сортировка по фамилии делается сама.
- `limits` — лимиты по умолчанию: насколько можно уменьшать текст Писания (%), сколько символов в тезисе и цитате.

## Свои файлы переводов

Формат — XML как у Beblia (`<bible><book number><chapter number><verse number>`). Форма понимает и формат Zefania (`XMLBIBLE` / `BIBLEBOOK` / `CHAPTER` / `VERS`), как у файлов для Holyrics.

### Переводы Андрея Десницкого

`bibles/RussianDesnitskyBible.xml` — сделан из модуля MyBible «Десн» (2024), автор модуля Oleg Safonov. Сноски, ударения и разметка убраны, текст не менялся. 48 книг, нумерация как в Синодальном.

Условия автора: переводы можно свободно читать и в любых объёмах цитировать в некоммерческих изданиях, указав авторство. Коммерческое использование — только с письменного разрешения автора. Изменять текст запрещено. Источник: https://perevod.desnitsky.net/

«Свой перевод» встроен в форму и в настройках не указывается: книга, глава, стихи, текст и название перевода вводятся вручную.
