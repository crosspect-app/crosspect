# Crosspect

Форма для проповедников церкви «Слово веры» (Познань): проповедник собирает конспект проповеди из блоков (места Писания, тезисы, цитаты, картинки, видео), а команда проекции получает всё в одном формате и делает по нему слайды.

## Что в репозитории

| Папка | Что там |
|---|---|
| `data/` | Настройки формы (`config.json`): переводы Библии, проповедники, лимиты. Описание — в [`data/README.md`](data/README.md) |
| `data/bibles/` | Переводы, которых нет в общем источнике Beblia |

Форма при запуске читает `data/config.json` из этого репозитория. Чтобы добавить перевод или проповедника, достаточно поправить этот файл — сама форма не меняется.

## Лицензия

Код распространяется по лицензии GPL-3.0 (файл `LICENSE`). Тексты переводов Библии в `data/bibles/` под неё не подпадают: у каждого перевода свои условия, они указаны в [`data/README.md`](data/README.md).
