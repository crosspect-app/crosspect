# Crosspect — состояние проекта

Обновлено: 11 ноября 2026 (этап 5). Код формы: [`index.html`](index.html), [`css/`](css), [`js/`](js). Устройство кода: [`ARCHITECTURE.md`](ARCHITECTURE.md). Правила для Claude: [`CLAUDE.md`](CLAUDE.md).

## Что это

Crosspect — браузерная форма церкви «Слово веры» (Познань). Проповедник собирает конспект проповеди из блоков в одном формате, вместо Telegram, Word, Google Диска и PPTX. Виталий по нему делает слайды (Canva / Holyrics), часть слайдов форма собирает сама в JPEG. Оператор на служении смотрит конспект с телефона.

Название: Cross (крест) + -spect («смотреть»: inspect, aspect). По-русски созвучно со словом «конспект».

Решено: форма станет **обязательной** для всех проповедников. Серии проповедей пока не рассматриваем.

## Как сейчас работать

- Форма открывается по ссылке `https://crosspect-app.github.io/crosspect/`. Версия всегда свежая; ничего скачивать и обновлять не нужно.
- **Вход.** Сначала форма просит войти через Google (почта должна быть среди участников пространства). Кто не вошёл, может нажать «Продолжить без входа»: тогда всё работает, как раньше, с черновиками в браузере и файлами. «Войти в облако» — в меню «⋯». Ссылка на проповедь (`#s=<id>`) после входа открывает эту проповедь.
- **Облако.** Проповеди лежат в Firestore; «Сохранить» (Ctrl+S) отправляет проповедь туда. Пока автосохранения нет (этап 6): не нажали «Сохранить» — правки остаются только в браузере (черновик не теряется, на главной помечен «Не сохранено в облако»). Файл `.json` — «⋯ → Скачать файл».
- Без входа «Сохранить» (Ctrl+S) скачивает файл `.json` с проповедью — его можно переслать. «Открыть» загружает `.json` или **старый HTML-файл проповеди**, сохранённый прежней формой. Старые файлы сами переводятся на новую модель (см. «Блоки»).
- Черновик сам сохраняется в браузере (localStorage). У ссылки на Pages свой черновик: то, что было в старой форме на компьютере, туда не перейдёт. Старую проповедь нужно один раз открыть через «Открыть» и сохранить.
- Проповедник прислал исправленный файл: «Открыть» → выбрать файл. Отметки «готово», которые ставил Виталий, в чужом файле не сохраняются.
- Интернет нужен для шрифтов, настроек и текстов Библии.
- Основной браузер — Chrome. Выгрузку слайдов делает только Виталий.
- Выгрузка JPEG работает только по ссылке на сайт (или с локального сервера): со страницы, открытой двойным щелчком из папки, браузер не даёт прочитать стили слайда.

## Что умеет форма

### Экраны
- **Главная** — список проповедей, сохранённых в этом браузере: карточки с заставкой, статусом (черновик / в работе / готово — считается по отметкам слайдов), датой, проповедником и полосой «готово»; ближайшие сверху, остальные таблицей; поиск по названию, проповеднику и местам Писания; «Новая проповедь», «Открыть файл», удаление черновика. Ссылка `#s=<id>` ведёт прямо в проповедь, «Назад» в браузере и перезагрузка работают.
- **Слайды** (тёмный): слева лента слайдов (миниатюры настоящие, у заметки — жёлтая плашка, у «доработать» оранжевый флажок, у «готово» зелёная галочка, внизу «Добавить»); в центре выбранный слайд, над ним «Название», JPEG, «Доработать», «Готово» и стрелки, под ним «Текст к слайду»; справа настройки слайда (те же поля, что раньше были в карточках) и действия: выше, ниже, дублировать, удалить.
- **Текст** (светлый, как документ): название, строка с датой и проповедником, слайды списком с миниатюрами и текстом под каждым (текст к слайду правится прямо тут); справа «Для оператора» (PDF), «Показать» (всё / только слайды, размер A− A+) и «Проверка» (у всех ли слайдов есть названия, сколько отмечено «доработать»). Клик по миниатюре открывает слайд.
- Шапка: «Проповеди» (на главную), название и строка «дата · проповедник» (клик открывает окно «О проповеди»), статус, переключатель «Слайды / Текст», «Сохранить», меню «⋯». Новая проповедь сразу открывает окно «О проповеди».
- Дата (по умолчанию ближайшее воскресенье), проповедник из списка (из настроек) или «Другой — ввести вручную»: имя и фамилия отдельными полями (на заставке «Имя ФАМИЛИЯ»). Интерфейс на Inter, заголовки и логотип на Unbounded. «Слайды» и главная всегда тёмные, «Текст» всегда светлый (тема по системе убрана).

### Вход и облако
- **Экран входа** (`js/cloud.js`): «Войти через Google», «Продолжить без входа»; если почты нет среди участников — «Вас нет в списке» с кнопкой «Войти другой почтой»; если облако не отвечает — «Облако недоступно» с «Повторить». Внутри Telegram и подобных приложений Google не пускает на вход: форма подсказывает открыть ссылку в Chrome или Safari.
- **Главная после входа**: проповеди пространства из облака (список обновляется сам, пока открыта главная; в закрытом пространстве проповедник видит только свои), название пространства и «имя · роль» в шапке. Если в браузере есть несохранённые правки облачной проповеди — показывается она с пометкой «Не сохранено в облако». Проповеди, которых в облаке нет (старые черновики), — отдельный раздел «Только в этом браузере» с кнопкой «В облако». Корзина удаляет проповедь из облака у всех (с подтверждением). Выйти — «⋯ → Выйти».
- **Сохранение**: в шапке «● Не сохранено в облако» / «Сохраняю…» / «✓ Сохранено в облаке в 15:20». Если пока вы правили, ту же проповедь сохранили в облаке, форма ничего не затирает, а спрашивает: «Взять облачную», «Сохранить копией» (новый номер, «(копия)» в названии) или «Заменить облачную». Проповедник открывает чужую проповедь для чтения, но сохранить её в облако не может (в шапке об этом сказано; можно «Сохранить копию»). Новая проповедь проповедника сразу с его именем и фамилией из списка участников.
- **Открыть файл**: один файл открывается как раньше (после входа его первое сохранение создаёт проповедь в облаке; если такая уже есть — вопрос про конфликт). Несколько файлов сразу после входа уходят прямо в облако; что там уже есть, пропускается.
- Хозяин облачной проповеди — тот, кто её создал (для редактора это тоже он сам; передать другому и статусы «подана / в работе / готово» — этап 7). Отметки «готово» и «доработать» пока в самой проповеди.
- Проповедь в облаке — один документ, до 1 МБ (форма предупредит заранее).

### Блоки
Проповедь — это слайды по порядку и заметки оператору между ними. Отдельных блоков «Текст проповеди» больше нет: **у каждого слайда внизу поле «Текст к слайду»** — что проповедник говорит, пока слайд на экране (Ж, К, Ч, маркер; счётчик слов и время, 130 слов ≈ 1 мин). На экран текст не идёт, оператор видит его в виде «Текст» и в PDF. Текст без слайда живёт на **заставке**. Общее время текста — над лентой слайдов и в виде «Текст».

Окно «Что добавить?»: сверху широкая «Заставка» и узкая «Заметка оператору», ниже парами: Место Писания и Свободный слайд, Тезис и Цитата, Картинка и Видео.

1. **Заставка** — слайд с номером и своим JPEG: название проповеди, имя проповедника и дата берутся из шапки. Заставок в проповеди может быть сколько угодно.
2. **Заметка оператору** — не слайд. В редакторе жёлтая, в просмотре и PDF яркая плашка заглавными жирным; видна даже в режиме «Только слайды».
3. **Место Писания** — один слайд, части в отдельных карточках: места Писания (любые переводы), текст (переключатель «Заглавными буквами», по умолчанию включён), «Линия» (тонкая черта во всю ширину текста). Выбор: перевод → книга → глава → стихи (кнопки, Shift+клик, поле «1-3, 5», «Вся глава», «Сбросить»). Текст стиха можно править, ↺ возвращает исходный. Вид слайда: стихи «В строку» (по умолчанию; можно «Рамка пунктиром» вокруг стихов) или «Каждый с новой строки» (номера колонкой слева); «Стихи заглавными буквами» (по умолчанию включено); выравнивание слева / по центру и по вертикали (верх / центр / низ). «Продолжить на новом слайде» переносит вид слайда и «Показывать перевод на слайде».
4. **Тезис** — из нескольких частей: текст и «Линия». У каждой текстовой части своё выравнивание по горизонтали, размер (70–130%), «Заглавными буквами» и «Рамка пунктиром». Выравнивание по вертикали (верх / центр / низ) одно на весь слайд. Списки: «- » → точка, «1. » → нумерация с автопродолжением; Enter продолжает список, Enter на пустом пункте — выход.
5. **Цитата** — текст, автор («Имя Фамилия») и отдельное поле «Подпись» (мелко второй строкой); «Заглавными буквами» (по умолчанию выкл.); размер 70–110%.
6. **Картинка** («Найди сам» / «Пришлю отдельно»), **Видео** («Ссылка» / «Пришлю отдельно», тайминг, комментарий), **Свободный слайд**.

Над слайдом: скопировать название, скачать JPEG (заставка, Писание, тезис, цитата), «Доработать», «Готово». В правой панели: выше / ниже, дублировать, удалить. Между слайдами порядок меняют кнопками выше / ниже, вставляют слайд кнопкой «Добавить» (после выбранного).
- **Удалить слайд**: его текст к слайду не пропадает — переходит к слайду перед ним (или после, если удалили первый); «Вернуть» возвращает всё как было.
- **Дублировать слайд**: копия без текста к слайду, чтобы текст не оказался в проповеди дважды.

**Перевод старых файлов** (сделанных до 11 ноября 2026): кусок «Текста проповеди» становится текстом к слайду перед ним; если перед ним слайда нет или стояла галочка «Здесь вывести заставку» — на этом месте появляется заставка с этим текстом. Поэтому номера слайдов в старой проповеди могут сдвинуться. Проповедник «Фамилия Имя» делится на фамилию и имя; автор цитаты «Имя Фамилия, источник» — на автора и подпись.

### Названия слайдов (имена файлов для Holyrics)
- Заставка — `[1] заставка`.
- Писание — само, по первому месту на слайде: `[3] 1 КОР. 12_7-9,12` (синодальные сокращения, «:» → «_»).
- Цитата — само: `[4] цитата Оливер КАН` (источник после запятой отбрасывается).
- Тезис, картинка, видео, свободный — поле «Название слайда», номер `[N]` зашит и не стирается. Название тезиса по умолчанию собирается из первых слов текста (до 5 слов, целыми словами, в пределах лимита, без «и/не/к…» в конце), пока его не правили руками.
- Символы `\ / : * ? " < > |` не вводятся. Лимит 35 символов, обязательность — в настройках.
- Без обязательного названия нельзя перейти в вид «Текст», выгрузить и собрать PDF; при сохранении — выбор «Дописать названия» или «Сохранить без них».
- Подсказки: тезис «Сформируется само из первых слов текста», картинка «Фото Десмонд Досс», видео «История Николаса Винтона», свободный «Значения слова АГАПЕ».
- При добавлении тезиса и цитаты курсор сразу в тексте (на компьютере).

### Оформление текста
Панель: **Ж**, **К**, Ч, маркер (#ffde59 на слайде), «АА» (все прописные для выделенного куска), списки «•» и «1.» (в тезисе), «Убрать оформление». Несколько пробелов подряд сохраняются на слайде. Мягкие переносы при вставке убираются. Греческий и иврит везде выводятся шрифтом Inter / Noto Sans Hebrew жирным и не переводятся в заглавные (чтобы не терялись ударения).

### Отметки «доработать» и «готово», сворачивание
- Кнопка **«Доработать»** (в ленте — оранжевый флажок): слайд нужно сделать или поправить вручную. Картинка, видео и свободный слайд получают её сами при создании (в старых файлах — если ещё не «готово»); снимается и ставится вручную. В виде «Текст» и PDF не видна. Пока проповеди в файлах, флажок видят все, кто открыл форму; разделение по ролям — с облаком.
- Кнопка «Готово» (в ленте — зелёная галочка). Ставится сама при выгрузке, если её ещё нет; снимается вручную.
- Сворачивания блоков больше нет: в ленте виден каждый слайд, а подробности — только у выбранного.

### Выгрузка
- **JPEG 1920×1080** одного слайда — обычный файл с названием слайда.
- **«Скачать все слайды» / «Скачать неотмеченные слайды»** — ZIP-архив с папкой «2026-11-08 Название», заставки тоже. Картинки, видео и свободные слайды не собираются: их Виталий делает в Canva, название копирует кнопкой.
- **PDF для оператора** — «⋯ → PDF для оператора», в окне печати Chrome «Сохранить как PDF». Узкие страницы 80×170 мм под телефон. Внутри: номера и названия слайдов (заставка — карточка «Заставка» со своим номером), текст Писания, тезисы и цитаты, под каждым слайдом его текст тонким серым, заметки жёлтыми плашками. Подсказки для редактора (найти, пришлют, описания, ссылки, «доработать») не попадают. Слайд не разрывается между страницами.

### Настройки
- «⋯ → Настройки слайдов»: макет слайда со штрихованной областью текста; поля (по умолчанию 60 px от края панели со всех сторон); обязательность и длина названий; **размер стихов Писания** (общий, 100% = 48 px, 50–200%, по умолчанию 110%); диапазоны размеров тезиса и цитаты. Своё значение действует в этом браузере; «Скопировать для config.json» — чтобы сделать общим.
- **Шрифт как в Canva — теперь основной** (толщина 325 вместо 400, буквы плотнее −0,04 em, строки 1,05 вместо 1,25; Писание 110%). До проверки на проекторе в «Настройках слайдов» остаётся свёрнутый раздел «Плотность шрифта»: как в Canva весь текст (основной) / только стихи / прежний. Если в браузере Виталия раньше сохранены свои настройки слайдов, они главнее: вернуть общие — кнопка «Общие (по умолчанию)». После проверки на проекторе раздел убрать.
- «Лимиты»: до какого % уменьшать Писание (80%), тезис 220 и цитата 300 символов — превышение подсвечивается жёлтым.
- «Источник настроек»: ссылка на `config.json`, «Проверить и применить», «По умолчанию».

## Слайды (предпросмотр = итоговый JPEG)
- Кадр 1920×1080. Слои: чёрная основа; кремовая рамка #ecdfcf с зерном (отступ 14, радиус 34); панель (отступ 44, радиус 8) с градиентом «Ember».
- Текст #ecdfcf, Unbounded, плотность как в Canva (325, −0,04 em, строки 1,05); ссылка и номера стихов Bold.
- **Заставка**: название проповеди посередине, Unbounded 900, заглавными, слова не переносятся. Размер подбирается сам: от 200 px (коротко) до 110 px (три строки); если и так не влезает — мельче, предпросмотр предупреждает «длинное, лучше короче». Внизу тонкая линия, слева «Имя ФАМИЛИЯ» (фамилия жирным), справа дата «дд/мм», 44 px.
- Писание: базовый размер 48 px × общая настройка (по умолчанию 110%), ссылка 1,2083 em, подпись перевода «* Синодальный перевод» — 90% от размера стихов, внизу. Длинное место уменьшается до лимита. По вертикали «центр» и «низ» сдвигают текст в пределах свободного места (до подписи перевода с запасом).
- Рамка пунктиром (стихи «в строку», часть тезиса): 3 px, #ecdfcf 85%, скругление 12 px — толщину и шаг штриха проверить на проекторе.
- Тезис 50,4 px (100%), цитата 51,48 px (100%), автор 52 px в правом нижнем углу (имя обычным, фамилия жирным, заглавными; подпись мелко второй строкой).
- Переносы: короткие слова и предлоги приклеиваются к следующему, же/ли/бы к предыдущему, одно слово на последней строке не остаётся.

## Переводы Библии
- Список в `data/config.json` (23 перевода): русский (Синодальный, НРП, Кулаков, СРП РБО — НЗ, Десницкий, Библейская лига, Кассиан — НЗ), украинский (Огієнко, Турконяк, Хоменко, Сучасною мовою, НПУ — НЗ), польский (BW, UBG, BG, NBG, EIB, Słowo Życia — NT, NPD — NT), английский (NIV, KJV, NKJV, ESV). Встроенный запасной список — 22.
- «Свой перевод» встроен в форму: всё вводится вручную, поля без подсказок; при выборе всё очищается.
- Источник текстов — Beblia (`raw.githubusercontent.com/Beblia/Holy-Bible-XML-Format`), свои файлы — `data/bibles/`. Форматы Beblia и Zefania.
- Десницкий — из модуля MyBible (48 книг). Условия автора: некоммерческое использование с указанием авторства, текст не менять → в инструкции для проповедников сказать, что формулировки перевода не переписывают.
- СРП ВЗ — только у Виталия (Zefania из Holyrics), публично не выкладываем.
- Убраны: Восточный перевод, Куліш і Пулюй, RST 1900.

## Известные проблемы и ограничения
- Отметки «готово» и «доработать» хранятся в файле и черновике Виталия; в исправленном файле от проповедника их нет (картинка, видео и свободный слайд в нём снова «доработать»). Возврат «доработать» после правки проповедника — этап 7, в облаке.
- Старые HTML-файлы проповедей открываются, но сохраняются уже как `.json`.
- Выгрузка JPEG требует интернета (шрифты встраиваются в картинку).
- Как PDF для оператора открывается в Telegram на телефоне — не проверено.
- Поля, размер Писания, режим шрифта пока не записаны в `config.json` — действуют только в браузере Виталия.
- Отметки «готово» и «доработать» пока лежат внутри слайдов проповеди, поэтому в облаке их увидит и проповедник. Для них уже есть закрытый от проповедников документ `editor/state` — перенос туда на этапе 7.
- Автосохранения и замка ещё нет: два человека могут править одну проповедь, при сохранении второго форма спросит, чью версию оставить (этап 6 даст замок и автосохранение). Без сети в облако сохранить нельзя: черновик остаётся в браузере, повторить «Сохранить» позже.
- Вход Google проверен только в эмуляторе и в тестах с подменой: первый настоящий вход — задача Виталия (с компьютера и с телефона), см. ниже.
- Кто в облаке, видит только одно пространство: если почта состоит в нескольких, берётся первое (выбор — этап 9).
- Вид «Текст» по-прежнему не открывается, пока у слайдов нет обязательных названий.
- Слайд правится в правой панели, а не прямо на картинке слайда.

## Отложено (после облака)
- **Быстрый ввод ссылки**: вставить «Иак 1:2-4» или целый список → форма сама создаёт слайды (словарь сокращений из анализа выше).
- **Работа с готовым текстом**: вставить весь текст проповеди, найденные ссылки подсвечиваются с кнопкой «Сделать слайдом».
- Картинки через Google Диск церкви; фото с подписью и цитата с портретом; блок «Слово» для греческих/еврейских слов; темы слайдов (Ember / Dusk / новые).
- Помощник на церковном ПК для Holyrics; Telegram-бот.
- Короткая инструкция для проповедников и пример заполненной проповеди.
- **CR «Готовые слайды из Canva»** (идея Виталия, 11 ноября 2026): загрузить картинку вместо любого слайда (картинка, видео, свободный — или любой другой), снять с него «доработать»; своя заставка из Canva. В ленте, выгрузке JPEG/ZIP и PDF оператора — загруженная картинка, так ZIP становится полным набором слайдов для Holyrics. Хранение — в Firestore (JPEG 1920×1080, отдельный документ на картинку, бесплатного объёма хватит примерно на 2000 слайдов); Storage Firebase требует платный тариф, Диск — сложнее. Нужны новое поле в модели и правила с тестами. Не решено: заставка целиком из Canva или фон + текст Crosspect; кто загружает (редактор или и проповедник); заставка на проповедь, на серию или «взять из прошлой». Удобнее после этапа 7.
- **CR «Генератор фонов»** (идея Виталия, 11 ноября 2026): сейчас фон слайда собирается в CSS (`css/style.css`, `.sl-frame`): четыре радиальных градиента с цветами и положением, зерно (`--noise`, наложение `overlay` с прозрачностью), виньетка. Генератор — ползунки и цвета для этих параметров (узор градиента, цвета, зернистость, яркость) с живым слайдом, сохранение под именем, один фон — по умолчанию; фон выбирается у проповеди. Наборы хранятся в настройках пространства, то есть рядом с этапом 9 и «темами слайдов». Частично заменяет загрузку своих фонов из CR выше.

## Решения и предпочтения
- Дизайну нейросетей не доверяем; целевой вывод — JPEG, собранный из шаблона.
- Медиафайлы проповедник присылает отдельно, подписывая номером слайда.
- Telegraph для оператора отвергнут; сжатые данные в ссылке — тоже (лимит Telegram 4096 символов). Google Диск для настроек отвергнут (нужен ключ API).
- Код Виталию присылать целиком, не фрагментами. Тексты для пользователей — естественный русский, без канцелярита.
- Вход обязателен только по умолчанию: «Продолжить без входа» оставлен, чтобы старые черновики были доступны, пока их не перенесли (убрать, когда все перейдут).
- Облако: Firebase (вход Google + Firestore, без карты) + GitHub Pages; картинки потом через Диск церкви. Роли админ / редактор / проповедник, пространства для разных церквей. Подробно — `docs/PLAN.md`.
- Права (этап 4): проповедник правит только свои проповеди, сам ставит лишь «черновик» и «подана», удаляет только свой черновик; «в работе» и «готово» — редактор. Админ не может снять админа с себя. Новые пространства заводит только служебный скрипт — чтобы посторонние не заняли место в бесплатной базе (открыть для других церквей — потом, одним правилом). Ссылку для оператора делает тот, кто может править проповедь; открыть её может кто угодно по ключу.
- Плотность текста как в Canva — основная для всех текстов (подтвердить на проекторе).
- Заметка оператору остаётся отдельным блоком — узкий жёлтый мини-слайд в ленте.
