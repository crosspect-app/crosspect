# Crosspect — состояние проекта

Обновлено: 12 ноября 2026 (этап 7.8). Код формы: [`index.html`](index.html), [`css/`](css), [`js/`](js). Устройство кода: [`ARCHITECTURE.md`](ARCHITECTURE.md). Правила для Claude: [`CLAUDE.md`](CLAUDE.md).

## Что это

Crosspect — браузерная форма церкви «Слово веры» (Познань). Проповедник собирает конспект проповеди из блоков в одном формате, вместо Telegram, Word, Google Диска и PPTX. Виталий по нему делает слайды (Canva / Holyrics), часть слайдов форма собирает сама в JPEG. Оператор на служении смотрит конспект с телефона.

Название: Cross (крест) + -spect («смотреть»: inspect, aspect). По-русски созвучно со словом «конспект».

Решено: форма станет **обязательной** для всех проповедников. Серии проповедей — на этапе 10 (вместе с форматами фона у серии).

## Как сейчас работать

- Форма открывается по ссылке `https://crosspect-app.github.io/crosspect/`. Версия всегда свежая; ничего скачивать и обновлять не нужно.
- **Вход.** Без входа форма не работает (этап 8): сначала «Войти через Google». Пустят того, кого добавили в пространство (автором или редактором), и админа. Ссылка на проповедь (`#s=<id>&sp=<пространство>`) после входа открывает эту проповедь, даже если человек был в другом пространстве.
- **Пространства.** Админ всей формы — церковная почта Виталия (swpoznan.media@gmail.com, запись в базе `admins/…`): видит все пространства, в каждом может всё, что редактор, плюс (с этапа 10) люди и настройки пространства. Редактор и автор видят только те пространства, куда их добавили. У кого пространств несколько (и у админа) — **выбор пространства в шапке главной**: проповеди и настройки слайдов у каждого свои; форма помнит, где человек был в прошлый раз.
- **Облако.** Проповеди лежат в Firestore. Проповедь открывается для просмотра; чтобы править, нажмите **«Редактировать»**: пока вы правите, остальные видят «Сейчас правит Иван (с 15:20)» и смотрят проповедь, которая обновляется у них сама. Правки уходят в облако сами (раз в 30 секунд, пока есть несохранённое); закончили — **«Сохранить»** (сохраняет и закрывает правку). Закончили конспект — в правке переключите статус в шапке на **«Готов к вёрстке»**: так редактор видит, что пора делать слайды (статус уходит в облако вместе с правками). Ошиблись — **↶ ↷** в шапке или Ctrl+Z / Ctrl+Y. Файл `.json` — «⋯ → Скачать файл».
- «⋯ → Скачать файл» — копия проповеди (`.json`) на компьютер; несохранённые правки она не отменяет, они всё равно уйдут в облако. Открыть файл в форме нельзя (с этапа 8; кнопки не было уже с 7.3).
- Несохранённые правки ждут в браузере (localStorage), пока не уйдут в облако.
- Интернет нужен для шрифтов, настроек и текстов Библии.
- Основной браузер — Chrome. Выгрузку слайдов делает только Виталий.
- Выгрузка JPEG работает только по ссылке на сайт (или с локального сервера): со страницы, открытой двойным щелчком из папки, браузер не даёт прочитать стили слайда.

## Что умеет форма

### Экраны
- **Главная «Конспекты»** (этап 7.8: «конспект» — документ в форме, «проповедь» — само событие) — конспекты текущего пространства из облака **одной таблицей** (этап 7.7): Дата, Название, Автор, Слайдов, Статус («Черновик» / «Готов к вёрстке» / «У редактора», у каждого свой цвет). Порядок всегда по дате: без даты — в самом верху, дальше от новых к старым (сортировку по заголовкам убрали на этапе 7.8); ближайшая предстоящая отмечена жёлтой чертой и «ближайшая». Фильтры над таблицей: дата (все / ближайшие / прошедшие / период «с … по …»), автор (из тех, кто есть в проповедях), статус (можно несколько); работают вместе с поиском по названию, автору и местам Писания; «Сбросить», когда что-то выбрано; «ничего не нашлось» с подсказкой. Фильтры форма помнит в этом браузере (`swp-home-view`). На узком экране строки — компактные карточки, фильтры — под кнопкой «Фильтры». «Слайдов» — без заставок (картинки, видео и свободные слайды, в том числе «пришлю отдельно», считаются; заметки — нет). «Новый конспект», удаление. Абзаца «Проповеди хранятся в облаке…» больше нет. Кнопка **«Как пользоваться»** в шапке (и в «⋯» везде) открывает страницу инструкции `#help` — пока пустую, с «Назад»; из конспекта в правке туда и обратно — правка не закрывается. Фон (этап 7.8) — **стена слайдов**: заставки с библейскими названиями на русском, украинском, польском и английском в цветах формата по умолчанию, затемнены (яркость 51 %, контраст 80 %) и с зерном; поверх тёмная дымка с одним «окном», которое за ~70 с плывёт по экрану; при «Уменьшить движение» дымка стоит. Ссылка `#s=<id>` ведёт прямо в проповедь, «Назад» в браузере и перезагрузка работают.
- **Слайды** (тёмный): слева лента слайдов (миниатюры настоящие, у заметки — жёлтая плашка, у «доработать» (видят только редактор и админ) оранжевый флажок, внизу «Добавить в конец»). Ширину ленты, слайда и правой панели можно тянуть за границы, а панели — менять местами, перетащив за заголовок (раскладка запоминается у человека в облаке, на всех компьютерах одинаково). Кто панели не переставлял, видит порядок пространства: его задают админ и редактор в «Настройках слайдов → Расположение панелей» (по умолчанию «Миниатюры, Слайд, Редактор»); «⋯ → Сбросить настройки экрана» убирает свой порядок и возвращает порядок пространства; на узком экране — как раньше. Пока проповедь правится, «+» перед первым и после последнего слайда видны всегда (этап 7.8, вместо «Добавить в конец»), «+» между слайдами — при наведении; слайды в ленте **перетаскивают** (мышью; на телефоне — подержать палец, пока слайд не приподнимется, и вести; с клавиатуры — Alt+↑/↓): слайд приподнят, идёт за указателем, соседи плавно раздвигаются, у края лента плавно прокручивается сама; отпустили — слайд мягко встаёт на место (этап 7.7), а **«+» между слайдами** вставляет новый на это место (на компьютере «+» виден при наведении). В центре выбранный слайд, над ним «Название», JPEG, «Доработать» (только редактору) и стрелки, под ним «Текст к слайду»; справа настройки слайда (колонка шире, чем раньше). **«Дублировать» и «Удалить»** — значками на миниатюре в ленте (внизу справа, в строке с названием): появляются при наведении и при фокусе с клавиатуры, на телефоне и планшете у выбранной миниатюры видны всегда; в просмотре значков нет. У заставки три строки справа («Название для Holyrics», «Название на слайде», «Внизу слайда») — серый текст без рамки поля: их не вводят, а показывают; при «Заставка: только название» в «Внизу слайда» написано, что низ не показывается.
- **Текст** (светлый, как документ): название, строка с датой и проповедником, слайды списком с миниатюрами и текстом под каждым (текст к слайду правится прямо тут); справа «Для оператора» (PDF), «Показать» (всё / только слайды, размер A− A+) и «Проверка» (у всех ли слайдов есть названия, сколько отмечено «доработать»). Клик по миниатюре открывает слайд.
- Шапка: знак Crosspect (в шапке проповеди — один знак, на главной и экране входа — знак с надписью CROSSPECT), «Проповеди» (на главную), название и строка «дата · автор» (клик открывает окно «О проповеди»), переключатель статуса «Черновик / Готов к вёрстке / У редактора», переключатель «Слайды / Текст», ↶ ↷ (пока проповедь правится), «Сохранить», меню «⋯». Новая проповедь сразу открывает окно «О проповеди».
- **Окно «О проповеди»** (этап 7.8): название; дата — три ближайших воскресенья кнопками («ближайшее» помечено) и «Другая дата…» — свой календарь (Unbounded, воскресенья жёлтым, сегодня в рамке, зелёная точка — на эту дату уже есть конспект, «Ближайшее воскресенье», «Сегодня»); дата не из трёх воскресений — отдельной кнопкой. Автор — свой список: если в пространстве есть авторы (пока `preachers` из `config.json`) — «Выберите автора», имена, линия, «Ввести вручную» (только тогда появляются «Имя» и «Фамилия»); если авторов нет — нераскрывающееся «Ввести вручную» и сразу имя и фамилия. Новый конспект: автор — вы, если ваше имя из записи участника есть в списке авторов; данные аккаунта Google не берутся. На заставке «Имя ФАМИЛИЯ». Интерфейс на Inter, заголовки и логотип на Unbounded. «Слайды» и главная всегда тёмные, «Текст» всегда светлый (тема по системе убрана).

### Вход и облако
- **Заставка при открытии формы** (этап 7.7, 7.8 — без шапки сверху; знак собирается со жёлтого клина, потом кремовые части): знак собирается, шевелится зерно; держится не меньше ~1,5 с при любой скорости связи, потом расплывается (~0,5 с) в список. При возврате из проповеди в список заставки нет; при «Уменьшить движение» — без задержки и размытия. Если облако отвечает дольше, под знаком появляется «Подключаюсь к облаку…».
- **Экран входа** (`js/cloud.js`): только «Войти через Google» («Продолжить без входа» убрано на этапе 8); если почты нет ни в одном пространстве — «Вас нет в списке»: к кому писать (ссылка на swpoznan.media@gmail.com, `CONTACT_EMAIL`) и кнопка «Войти другой почтой»; админ, у которого ещё нет ни одного пространства, — «Пространств пока нет»; если облако не отвечает — «Облако недоступно» с «Повторить». Внутри Telegram и подобных приложений Google не пускает на вход: форма подсказывает открыть ссылку в Chrome или Safari.
- **Главная после входа**: проповеди текущего пространства (список обновляется сам, пока открыта главная; в закрытом пространстве автор видит только свои), в шапке — название пространства или выбор пространства и «имя · роль» (роли: админ, редактор, автор). Список строится из маленьких **сводок** (`spaces/…/summaries/<id>`: название, дата, автор, статус, замок, число слайдов, места Писания для поиска), а не из целых конспектов: так меньше трафика из бесплатного запаса. Если в браузере есть несохранённые правки проповеди этого пространства (в том числе новой, которая ещё не дошла до облака, или копии, сделанной без сети) — показывается она с пометкой «Не сохранено в облако»; такую новую можно удалить корзиной («Удалить черновик»). Старые черновики из браузера, сделанные до облака, не показываются. Корзина удаляет проповедь из облака у всех (с подтверждением). Выйти — «⋯ → Выйти».
- **Замок и правка** (`js/lock.js`): облачная проповедь открывается «Только просмотр»: настройки слайдов и текст не правятся, щелчок по ним подсказывает «Редактировать», «Добавить», «Доработать», «Готово» и окно «О проповеди» закрыты. «Редактировать» берёт замок; если его держит другой — в шапке «Сейчас правит Иван (с 15:20)», кнопка неактивна, на карточке главной «Правит Иван». Редактор и админ видят «Забрать правку» (с подтверждением). Своя правка в другой вкладке или на другом устройстве — «Править здесь». Новая проповедь и файл, открытый после входа, сразу в правке.
- **Автосохранение**: раз в 30 секунд, пока есть несохранённые правки (Ctrl+S, «Сохранить», уход с проповеди и скрытие вкладки — сразу; так мы бережём общий бесплатный запас базы), в шапке «Не сохранено: уйдёт в облако само» / «Сохраняю…» / «✓ Сохранено в облаке в 15:20». Раз в минуту сигнал «я здесь». «Сохранить», уход с проповеди, «Выйти» — сохраняют и отпускают замок. Ничего не делали `lockMinutes` (10 минут, настройка пространства) — форма сохраняет, отпускает и пишет «Правка закрыта» с кнопкой «Править дальше». Закрыли вкладку — замок сам истечёт через 10 минут после последнего сигнала. Перезагрузили страницу посреди правки — правка продолжается.
- **Запас базы исчерпан** (бесплатный дневной лимит Firestore, обновляется в 9:00 по Варшаве): форма не говорит «нет прав», а пишет «Облако перегружено до 9:00»; правки ждут в браузере, форма пробует снова раз в несколько минут, Ctrl+S — сразу.
- **Нет сети**: правки копятся в черновике браузера, в шапке «Нет связи…», уходят сами, когда сеть вернётся. Начать правку без сети нельзя (нужен замок).
- **Замок забрали** (редактор, или вы сами в другой вкладке), а у вас были несохранённые правки — они уходят отдельной копией «… (копия)» (без сети — в браузер, раздел «Только в этом браузере»), окно «Правку забрали» с кнопкой «Открыть копию»; чужие правки не затираются. Открыли проповедь с несохранёнными правками в браузере, а её сейчас правит другой — так же, копией.
- **Конфликт без замка** (проповедь изменили, пока ваш замок был потерян, например без сети): форма не затирает и спрашивает «Взять облачную», «Сохранить копией» или «Заменить облачную»; пока не выбрали, в облако ничего не уходит (в шапке «Не сохранено: в облаке другая версия. Выбрать»).
- Автор открывает чужую проповедь только для чтения: «Только чтение: проповедь другого автора», вместо «Редактировать» — «Сделать копию» (копия станет его проповедью). Новая проповедь для любой роли сразу с вашим именем (из списка участников, а если там пусто — из аккаунта Google); в «О проповеди» автора можно сменить, например когда редактор делает проповедь за другого.
- Открыть файл нельзя: кнопки нет с этапа 7.3, кода — с этапа 8. Старые черновики из браузера в облако не переносятся (решение Виталия: они не нужны).
- Удалить проповедь, которую сейчас правит другой, нельзя: форма скажет, кто правит.
- Хозяин облачной проповеди — тот, кто её создал (для редактора это тоже он сам; передать другому — потом).
- **Статус конспекта** (этап 7.3) — три: «Черновик» (новый конспект), «Готов к вёрстке» (автор закончил) и «У редактора» (конспект взял редактор). Переключатель — в шапке проповеди, три положения; в списке проповедей статус только виден. Пока в конспекте нет ни одного слайда, «Готов к вёрстке» и «У редактора» неактивны («Сначала добавьте слайды», этап 7.8). Статус меняется **только в режиме правки**, как обычная правка: уходит в облако с автосохранением или по «Сохранить», правку не закрывает, в отмену (↶) не входит. В просмотре щелчок по переключателю подсказывает «Редактировать». «Черновик» ↔ «Готов к вёрстке» — без ограничений и в любую сторону; сам он больше не сбрасывается. **«У редактора»** ставит и снимает только редактор или админ (у автора это положение неактивно). Пока стоит «У редактора», автор конспект не правит: «Редактировать» неактивна, в шапке «Конспект у редактора: если нужны правки, напишите ему», щелчок по полям — та же подсказка; удалить его тоже нельзя; «⋯ → Сделать копию» можно (копия — новый черновик автора). Это проверяет и база (правило в `cloud/firestore.rules`). Если автор правил, а редактор забрал правку и поставил «У редактора», у автора — обычное «Правку забрали» с копией несохранённого. В облаке `draft` / `submitted` / `work`; старое `done` считается «У редактора».
- **Отмена и возврат** (этап 7.2): ↶ ↷ в шапке и Ctrl+Z / Ctrl+Y (Ctrl+Shift+Z), серые, когда нечего отменять. Отменяется любая правка содержимого: добавить, удалить, переставить слайд, вид, текст (набор в одном поле подряд — один шаг). Внутри поля, где печатают, Ctrl+Z сначала отменяет набор в самом поле, как в браузере, потом — действия со слайдами. «Доработать» и статус в отмену не входят. История живёт до конца правки: автосохранение её не стирает, «Сохранить» и уход с проповеди — сбрасывают. В просмотре кнопок нет.
- **«Доработать»** — только у редактора и админа (автор не видит ни флажка, ни кнопки, ни счётчика). Ставится и снимается в любой момент, замок не нужен, и проповедь при этом не записывается: отметки лежат в закрытом документе `editor/state`, который автор прочитать не может. Картинка, видео и свободный слайд просят доработки сами, пока редактор не снимет. Если после этого автор изменит слайд, отметка вернётся сама (форма сравнивает подпись содержимого слайда на момент, когда редактор отметку снял); собственные правки редактора её не возвращают. Над лентой счётчик «N доработать»: щелчок оставляет в ленте только такие слайды, ещё щелчок — все. Отметки уходят в облако через 1–2 секунды после щелчка.
- Проповедь в облаке — один документ, до 1 МБ (форма предупредит заранее).

### Блоки
Проповедь — это слайды по порядку и заметки оператору между ними. Отдельных блоков «Текст проповеди» больше нет: **у каждого слайда внизу поле «Текст к слайду»** — что проповедник говорит, пока слайд на экране (Ж, К, Ч, маркер; счётчик слов и время, 130 слов ≈ 1 мин). На экран текст не идёт, оператор видит его в виде «Текст» и в PDF. Текст без слайда живёт на **заставке**. Общее время текста — над лентой слайдов и в виде «Текст».

Окно добавления (заголовок «Добавить после Слайда 10», «Добавить в конец» или «Добавить в начало»): плитки парами одного размера — «Заставка проповеди» и «Место Писания», «Тезис» и «Цитата», «Картинка» и «Видео», «Свободный слайд» и «Заметка оператору».

1. **Заставка проповеди** — слайд с номером и своим JPEG: название проповеди, имя автора и дата берутся из шапки (или только название — настройка «Заставка: только название»). Заставок в проповеди может быть сколько угодно. Размер названия −/+ в правой панели — один на всю проповедь: меняешь на любой заставке — меняются все (хранится в проповеди, `settings.splash`, в %).
2. **Заметка оператору** — не слайд. В редакторе жёлтая, в просмотре и PDF яркая плашка заглавными жирным; видна даже в режиме «Только слайды».
3. **Место Писания** — один слайд, части в отдельных карточках: места Писания (любые переводы), текст (переключатель «Заглавными буквами», по умолчанию включён), «Линия» (тонкая черта во всю ширину текста, сверху или снизу — где стоит). Выбор: перевод (отдельной строкой на всю ширину, над книгой) → книга → глава → стихи (кнопки, Shift+клик, поле «1-3, 5», «Вся глава», «Сбросить»). Текст стиха можно править, ↺ возвращает исходный. **Вид стихов общий для всех слайдов Писания** и задаётся в «Настройках слайдов» (автор его не меняет): «В строку» или «С новой строки», «Рамка пунктиром» (с новой строки — одна рамка на все стихи), «Стихи заглавными буквами», «Показывать перевод на слайде», выравнивание слева / по центру / справа и по вертикали (верх / центр / низ). С новой строки слева номера стоят колонкой; по центру и справа номер стоит перед стихом, и выравнивается сам текст стихов.
4. **Тезис** — из нескольких частей: текст и «Линия». У каждой текстовой части своё выравнивание по горизонтали, размер (70–130%), «Заглавными буквами» и «Рамка пунктиром». Выравнивание по вертикали (верх / центр / низ) одно на весь слайд. Списки: «- » → точка, «1. » → нумерация с автопродолжением; Enter продолжает список, Enter на пустом пункте — выход.
5. **Цитата** — текст, автор («Имя Фамилия») и отдельное поле «Подпись» (мелко второй строкой); «Заглавными буквами» (по умолчанию выкл.); размер 70–110%.
6. **Картинка** («Найди сам» / «Пришлю отдельно»), **Видео** («Ссылка» / «Пришлю отдельно», тайминг, комментарий), **Свободный слайд**.

Над слайдом: скопировать название, скачать JPEG (заставка, Писание, тезис, цитата; у картинки, видео и свободного — пустой слайд: рамка и фон без текста, основа для Canva), «Доработать» (только редактору). В правой панели: дублировать, удалить. Порядок меняют перетаскиванием в ленте; вставляют слайд «+» между слайдами или «Добавить в конец». Номера и названия `[N]` пересчитываются сами.
- **Удалить слайд**: его текст к слайду не пропадает — переходит к слайду перед ним (или после, если удалили первый); «Вернуть» возвращает всё как было. Выбран становится следующий слайд (удалили последний — предыдущий).
- **Дублировать слайд**: копия без текста к слайду, чтобы текст не оказался в проповеди дважды.

**Перевод старых файлов** (сделанных до 11 ноября 2026): кусок «Текста проповеди» становится текстом к слайду перед ним; если перед ним слайда нет или стояла галочка «Здесь вывести заставку» — на этом месте появляется заставка с этим текстом. Поэтому номера слайдов в старой проповеди могут сдвинуться. Проповедник «Фамилия Имя» делится на фамилию и имя; автор цитаты «Имя Фамилия, источник» — на автора и подпись.

### Названия слайдов (имена файлов для Holyrics)
- Заставка — `[1] Заставка Название проповеди` (без кавычек; длинное обрезается по длине названия слайда, целыми словами).
- Писание — само, по первому месту на слайде: `[3] 1 КОР. 12_7-9,12` (синодальные сокращения, «:» → «_»).
- Цитата — само: `[4] цитата Оливер КАН` (источник после запятой отбрасывается).
- Тезис, картинка, видео, свободный — поле «Название слайда», номер `[N]` зашит и не стирается. Название тезиса по умолчанию собирается из первых слов текста (до 5 слов, целыми словами, в пределах лимита, без «и/не/к…» в конце), пока его не правили руками.
- Символы `\ / : * ? " < > |` не вводятся. Длина — в «Настройках слайдов» (по умолчанию 35 символов); название обязательно всегда.
- Без обязательного названия нельзя перейти в вид «Текст», выгрузить и собрать PDF; при сохранении — выбор «Дописать названия» или «Сохранить без них».
- Подсказки: тезис «Сформируется само из первых слов текста», картинка «Фото Десмонд Досс», видео «История Николаса Винтона», свободный «Значения слова АГАПЕ».
- При добавлении тезиса и цитаты курсор сразу в тексте (на компьютере).

### Оформление текста
Панель: **Ж**, **К**, Ч, маркер (#ffde59 на слайде), «АА» (все прописные для выделенного куска), списки «•» и «1.» (в тезисе), «Убрать оформление». Стоит над полем, где идёт набор (в «Тексте к слайду» — в его заголовке), а не внизу экрана. Несколько пробелов подряд сохраняются на слайде. Мягкие переносы при вставке убираются. Греческий и иврит везде выводятся шрифтом Inter / Noto Sans Hebrew жирным и не переводятся в заглавные (чтобы не терялись ударения).

### Отметка «доработать»
- Кнопка **«Доработать»** над слайдом (в ленте — оранжевый флажок; в боковой панели отметки больше нет): слайд нужно сделать или поправить вручную. Видят и ставят только редактор и админ; в облаке — вне замка, подробности в разделе «Вход и облако». Картинка, видео и свободный слайд получают её сами. В виде «Текст» (для редактора) метка «доработать», в PDF не видна.
- Отметки «готово» у слайдов больше нет: у проповеди целиком статус «Черновик», «Готов к вёрстке» или «У редактора». В старых файлах «готово» только решает, просить ли у картинки доработки.
- Сворачивания блоков нет: в ленте виден каждый слайд, а подробности — только у выбранного.

### Выгрузка
- **JPEG 1920×1080** одного слайда — обычный файл с названием слайда. У картинки, видео и свободного слайда — пустой слайд (рамка и фон); в ZIP они не попадают.
- **«Скачать все слайды»** — ZIP-архив с папкой «2026-11-08 Название», заставки тоже. Картинки, видео и свободные слайды не собираются: их Виталий делает в Canva, название копирует кнопкой.
- **PDF для оператора** — «⋯ → PDF для оператора», в окне печати Chrome «Сохранить как PDF». Узкие страницы 80×170 мм под телефон. Внутри: номера и названия слайдов (заставка — карточка «Заставка» со своим номером), текст Писания, тезисы и цитаты, под каждым слайдом его текст тонким серым, заметки жёлтыми плашками. Подсказки для редактора (найти, пришлют, описания, ссылки, «доработать») не попадают. Слайд не разрывается между страницами.

### Настройки
- **«⋯ → Настройки слайдов»** (этапы 7.1 и 7.2) — **общие для всего пространства**, лежат в облаке (`spaces/…/config/slides`). Видят и меняют только админ и редактор, у авторов пункта нет. «Применить» активна, только если в окне что-то изменили; нажали — настройки сразу действуют во всех проповедях, старых и новых, у всех, у кого форма открыта; окно при этом остаётся открытым («✓ Применено» у кнопки), а кнопка снова неактивна. Кнопки «Закрыть» внизу нет: крестик или Esc, неприменённое при этом просто не применяется. Объяснения — только во всплывающих подписях (текстовых подсказок под полями в форме больше нет). Пока облако не ответило, действует последняя копия настроек этого пространства в браузере (или значения по умолчанию). Раздел `"slides"` и `"limits"` в `config.json` больше ни на что не влияет.
- Окно: слева живой пример слайда (заставка / Писание / тезис / цитата; пример меняется сразу, проповеди — только после «Применить»), справа пять блоков. **Общие настройки**: шрифт кириллицы и латиницы (Unbounded), для греческого (Inter), для иврита (Noto Sans Hebrew) — пока по одному в списке; длина названия слайда (35); поля слайда (60 px от края панели; пока курсор в поле, на примере видна область текста). **Расположение панелей** (этап 7.4): три плашки в ряд — «Миниатюры», «Слайд», «Редактор»; порядок слева направо — по умолчанию для всего пространства (у тех, кто не переставлял панели у себя). Плашки переставляют мышью или пальцем (перетащить), стрелками ← → на плашке или с клавиатуры (фокус на плашке и ← →). Применяется кнопкой «Применить», как всё в окне; у всех, у кого форма открыта, порядок меняется сразу. **Настройки для видов слайдов** (таблица): размер 100% в px (заставка 200, имя и дата 44, Писание 52,8, тезис 50,4, цитата 51,48), «Уменьшение до» в % (заставка 55 — предел «−» и до какого размера название уменьшается само, чтобы влезть в три строки; Писание 80 — меньше форма советует разбить слайд; тезис и цитата 70 — предел «−»), «Увеличение до» (заставка 130, тезис 130, цитата 110 — предел «+»), расстояние между символами и между строками (название заставки 0 и 1,1; имя и дата −0,03 и 1,1; Писание, тезис, цитата −0,04 и 1,05), «Лимит, симв.» (тезис 220, цитата 300 — больше подсвечивается жёлтым). **Место Писания**: в строку / с новой строки, рамка, заглавные, перевод, выравнивание; «Между стихами» (0,3 em, только с новой строки) и «Между ссылкой и текстом» (0,85 em). Под таблицей видов слайдов — **«Заставка: только название»** (выкл.): на всех заставках только название посередине, без линии, имени и даты (строка «Заставка: имя и дата» тогда неактивна).
- **Фон — форматы** (этапы 7.3 и 7.5). Формат — именованный фон пространства (только фон: шрифты, размеры, поля, вид стихов и заставка остаются общими настройками). Форматы общие для пространства и лежат в облаке вместе с настройками слайдов (`config/slides`: `formats`, `defaultFormat`); видят и меняют админ и редактор. Во всех проповедях пространства рисуется **формат по умолчанию** (с этапа 10 — если у проповеди и её серии не выбран свой).
  - **System Template** — встроенный формат, прежний фон «Ember» один в один. В облаке не хранится, его нельзя изменить (ползунки серые, «Сохранить» неактивна) и удалить; можно «Копировать» и «Создать новый». Пока других форматов нет, он стоит по умолчанию.
  - Строка форматов над ползунками: **выбор формата** (формат по умолчанию помечен «· по умолчанию»; выбор показывает формат в примере слайда и на ползунках, на проповеди не влияет), **«Создать новый»** (чёрный фон, все ползунки на нуле, оттенков 1, название пустое), **«Копировать»** (копия с настройками, как сейчас на ползунках, и с тем же названием — сохранить её можно, только поменяв название), **«Удалить»** (с подтверждением; удалили формат по умолчанию — по умолчанию снова System Template), **«Сделать по умолчанию»** (активна у сохранённого формата без несохранённых правок). Ниже — **«Название формата»** (задаётся только новому формату и копии; у сохранённого не меняется; названия не повторяются без учёта регистра и пробелов по краям) и **«Сохранить»** (активна, только когда есть что сохранить). Почему кнопка неактивна — во всплывающей подписи.
  - Действия с форматами записываются в облако сразу, у них своя кнопка; «Применить» — для остальных настроек окна и форматы не трогает. Если в формате есть несохранённые правки, а человек выбирает другой формат, создаёт новый или закрывает окно, форма спрашивает: «Сохранить», «Не сохранять» или «Отмена» (у нового формата без названия или с занятым названием — «Вернуться к формату» или «Не сохранять»).
  - Ползунки (этап 7.3): «Полосы по вертикали», «Полосы по горизонтали», «Пятна» (0–100, их можно смешивать), «Оттенков» (1–20), «Основной цвет», «Разброс оттенков» (сначала оттенки близки к основному, дальше — всё дальше по цветовому кругу), «Размытие», «Зернистость» и вид зерна (мелкое / крупное / цветное), «Яркость основы», «Затемнение краёв». «Другой вариант» перетасовывает пятна и полосы при тех же настройках (номер варианта хранится: фон у всех одинаковый). «Сбросить фон» убрана (вместо неё — System Template). Рамка (#ecdfcf) не меняется. Узор рисуется один раз в картинку на набор настроек, поэтому лента не тормозит, а JPEG и ZIP — с тем же фоном, что и предпросмотр (в том числе пустой JPEG картинки, видео и свободного слайда). Единицы стоят внутри полей, подсказка — при наведении.
  - **Перенос с этапа 7.3**: если фон пространства уже настраивали, он стал форматом **«Фон пространства»** и форматом по умолчанию — на экране ничего не поменялось. В облако форматы уходят при первой записи настроек слайдов (старое поле `bg` больше не пишется).
- Шрифт как в Canva — для всех слайдов (толщина 325); переключателя «Плотность шрифта» больше нет. Название слайда обязательно всегда (переключателя нет). Окна «Лимиты» нет: лимиты общие.
- «Источник настроек» убран (этап 7.3): форма всегда берёт `data/config.json` из репозитория (переводы, список авторов, подпись перевода); свою ссылку, сохранённую раньше, забывает.

### Логотип (этап 7.4)
- Знак по `crosspect/logo.md`: речевой пузырь с хвостиком слева внизу, латинский крест из пустоты; левая часть и верхняя правая — кремовые, нижний правый клин — жёлтый. В светлом виде («Текст») знак тёмный, клин тёмно-жёлтый. Код — `js/logo.js` (SVG, цвета и анимация в CSS `.logo-mark`).
- Где стоит: шапка главной и экран входа — знак с надписью CROSSPECT (Unbounded Bold); шапка проповеди — один знак слева (щелчок ведёт на главную); favicon — знак на тёмной плитке (встроен в `index.html`, отдельного файла нет).
- **Анимация сохранения** (~1,9 с, без библиотек): все части гаснут, потом по очереди загораются зелёным (левая, верхняя правая, клин), цвета возвращаются. Части привязаны к настоящим стадиям: левая — черновик записан в браузере, верхняя правая — запрос в облако ушёл, клин — сервер подтвердил. Нет сети или запас базы исчерпан — горит одна левая часть; конфликт, замок забрали, ошибка — левая и верхняя правая; остаётся так до следующего сохранения или ухода на главную. Запускает её только «Сохранить» (и закрытие правки кнопкой); автосохранение раз в 30 секунд знак не трогает — рядом со статусом появляется тихая галочка (этап 7.6). Анимация знака идёт всегда, системная настройка «уменьшить анимацию» её не отключает (решение Виталия 12 ноября: в Windows она часто выключена).

### Лента без пересборки и фокус (этап 7.7)
- Лента, слайд в центре и правая панель **не пересобираются** при правке, автосохранении, «Сохранить», смене статуса, входе в правку и выходе, перестановке, добавлении, дублировании, удалении, отмене и обновлении из облака: миниатюры живут, пока жив слайд, перерисовывается только та, у которой изменилось содержимое; новая миниатюра появляется уже с текстом (шрифты и картинка фона готовы до первого показа). Сцена и правая панель меняются, только если выбран другой слайд (или изменился он сам, его номер, режим правки).
- **Выбранный слайд всегда на виду**: лента не прыгает, а если выбранный слайд за краем — плавно докручивается ровно до него. «Дублировать» — выбрана копия, она сразу под исходным, видны обе, если помещаются; «Удалить» — выбран следующий слайд (удалили последний — предыдущий); стрелки у сцены и Alt+↑/↓ — то же. Из «Текста» щелчок по слайду — в «Слайдах» он ближе к середине ленты.
- Открыть проповедь: список остаётся на месте, пока данные не готовы (дольше ~300 мс — серые заготовки ленты и слайда), потом экран проповеди въезжает справа (~250 мс). «← Проповеди» — проповедь уезжает вправо, список проявляется. Надписи «Открываю проповедь…» больше нет.
- Из «Слайдов» в «Текст» блок выбранного слайда подсвечивается ~2 с и медленно гаснет.
- Над лентой: «12 слайдов + 1 заставка» — слайды считаются так же, как в списке (без заставок); в виде «Текст» — так же.
- После «Дублировать» уведомление «Слайд скопирован» (у заметки — «Заметка скопирована»; если у слайда был текст — по-прежнему «Слайд скопирован без текста к нему»).

### Анимации интерфейса (этап 7.6)
- Короткие (120–250 мс), только сдвиг и прозрачность, без библиотек: `js/motion.js` + переменные `--motion-*` в `css/style.css`. Слайды (`.sl-*`) не анимируются никогда, при выгрузке JPEG и ZIP все анимации выключены.
- Лента: перетаскивание, «+», дублирование (копия вырастает и ~1 с в жёлтой рамке), удаление (слайд тает, остальные съезжают), отмена и возврат. С этапа 7.7 — на живых узлах (~250 мс), во время перетаскивания соседи раздвигаются.
- Статус: переключатель плавно переезжает и меняет цвет; жёлтый клин знака вспыхивает один раз, когда сам человек ставит «Готов к вёрстке». Автору при статусе «У редактора» на кнопке «Редактировать» виден замок.
- «Слайды ↔ Текст»: выбранная миниатюра перетекает на новое место (там, где браузер это умеет, иначе мгновенно). Щелчок по миниатюре в «Тексте» прокручивает к блоку и на полсекунды подсвечивает его.
- Автосохранение: рядом со статусом рисуется галочка и гаснет через ~1,5 с; при ошибке галочки нет.
- Уведомления выезжают снизу стопкой, у тех, что гаснут сами, тонкая полоска оставшегося времени; под курсором время стоит. Тексты не менялись.
- Загрузка главной — серые строки-заглушки с бегущим бликом, потом таблица плавно появляется. При открытии проповеди дольше ~300 мс — заготовки ленты и слайда (этап 7.7).
- Окно «Настройки слайдов»: пример слайда плавно сменяется при «Другой вариант» и выборе формата; ползунки без анимации.
- Экран входа: знак собирается из трёх частей (~0,9 с, один раз), на фоне живое зерно. Главная: очень медленно плывущий фон из картинки формата по умолчанию — с этапа 7.7 размыт меньше и ярче, чтобы читались цвета формата; строки таблицы на сплошной подложке.
- Системная настройка «уменьшить анимацию» (`prefers-reduced-motion`): всё мгновенно, зерно и фон стоят, знак на входе сразу целый; подсветки остаются без сдвигов. Анимация знака при сохранении — исключение (см. «Логотип»). Бесконечные анимации стоят, пока вкладка скрыта.

## Известные проблемы и ограничения
- Выгрузка JPEG требует интернета (шрифты встраиваются в картинку).
- Как PDF для оператора открывается в Telegram на телефоне — не проверено.
- Настройки слайдов из браузера Виталия (старое «только в этом браузере») не переносятся: в облаке сначала значения по умолчанию, свои нужно один раз ввести в окне и нажать «Применить».
- Собственный вид стихов у старых слайдов Писания (в строку / с новой строки, рамка, выравнивание) больше не действует: все слайды выглядят по общей настройке.
- Отметки «доработать» два редактора правят независимо: кто записал последним, того набор и остаётся (живого обновления отметок между редакторами нет, они подтягиваются при открытии проповеди). Если правка формы меняет то, как слайд хранится, отметки, которые редактор снял, могут один раз вернуться.
- Список проповедей на главной не показывает «доработать»: отметки лежат отдельно (их не видит автор), в сводку они не попадают.
- Сводку пишет форма вместе с проповедью. Вкладка со старой версией формы (открытая до выпуска этапа 8 и не перезагруженная) сводку не обновляет: карточка покажет старое, пока проповедь не сохранят в новой версии. Поправить сразу — «Пространства» → `migrate-8` ещё раз.
- Автосохранение раз в 30 секунд: за это время закрытая без «Сохранить» вкладка может потерять до 30 секунд правок (браузер при закрытии спрашивает «Покинуть сайт?»).
- Замок и автосохранение проверены в тестах (подмена облака в форме и настоящие правила в эмуляторе), вдвоём на живой базе — ещё нет (см. «Проверка этапа 6»).
- Закрыли вкладку посреди правки — другие видят «Сейчас правит…» ещё до 10 минут (пока не истечёт замок); редактор может забрать правку сразу.
- Живой ли чужой замок, форма считает по часам своего компьютера; если они сильно спешат или отстают, «Сейчас правит» может показаться дольше или короче. Окончательно решает база по своим часам.
- Правила базы (этап 4) пропускают правку без замка, если замка на проповеди нет совсем. Форма так не делает, а от такой чужой записи защищает проверка версии (окно «Проповедь уже изменили»).
- Вход Google проверен только в эмуляторе и в тестах с подменой: первый настоящий вход — задача Виталия (с компьютера и с телефона), см. ниже.
- Вид «Текст» по-прежнему не открывается, пока у слайдов нет обязательных названий.
- Слайд правится в правой панели, а не прямо на картинке слайда.
- «В строку» + «Рамка пунктиром» (замечание после 7.6: стихи будто бы шли каждый с новой строки): воспроизвести не удалось — во всех сочетаниях (выравнивание, заглавные, Иакова 2:17–18 и 1 Кор 13:1–2 Синодального, пример в окне настроек, ленте и на сцене) стихи идут одним абзацем в одной рамке; тест `test_inline_verses_with_frame_are_one_paragraph` это проверяет. Возможно, на скриншоте первый стих просто занял целую строку. Если повторится — нужен скриншот и какие стоят настройки «Места Писания».

Независимо от этапов (делает Виталий): тест на проекторе — шрифт как в Canva (теперь основной, Писание 110%), заставка (размер названия, линия, имя и дата) и рамка пунктиром (толщина и шаг штриха).

## Отложено (после облака)
- **Быстрый ввод ссылки**: вставить «Иак 1:2-4» или целый список → форма сама создаёт слайды (словарь сокращений из анализа выше).
- **Работа с готовым текстом**: вставить весь текст проповеди, найденные ссылки подсвечиваются с кнопкой «Сделать слайдом».
- Картинки через Google Диск церкви; фото с подписью и цитата с портретом; блок «Слово» для греческих/еврейских слов; темы слайдов (Ember / Dusk / новые).
- Помощник на церковном ПК для Holyrics; Telegram-бот.
- Короткая инструкция для проповедников и пример заполненной проповеди.
- **CR «Готовые слайды из Canva»** (идея Виталия, 11 ноября 2026): загрузить картинку вместо любого слайда (картинка, видео, свободный — или любой другой), снять с него «доработать»; своя заставка из Canva. В ленте, выгрузке JPEG/ZIP и PDF оператора — загруженная картинка, так ZIP становится полным набором слайдов для Holyrics. Хранение — в Firestore (JPEG 1920×1080, отдельный документ на картинку, бесплатного объёма хватит примерно на 2000 слайдов); Storage Firebase требует платный тариф, Диск — сложнее. Нужны новое поле в модели и правила с тестами. Не решено: заставка целиком из Canva или фон + текст Crosspect; кто загружает (редактор или и проповедник); заставка на проповедь, на серию или «взять из прошлой». Удобнее после этапа 7.
- **CR «Генератор фонов»** (идея Виталия, 11 ноября 2026). Сделано: генератор (этап 7.3), форматы с именами и формат по умолчанию (этап 7.5). Осталось: фон для серии проповедей и выбор формата в проповеди (этап 10), свои фоны из Canva. Исходное описание: фон слайда собирался в CSS (`css/style.css`, `.sl-frame`): четыре радиальных градиента с цветами и положением, зерно (`--noise`, наложение `overlay` с прозрачностью), виньетка. Генератор — ползунки и цвета для этих параметров (узор градиента, цвета, зернистость, яркость) с живым слайдом, сохранение под именем, один фон — по умолчанию; фон выбирается у проповеди. Наборы хранятся в настройках пространства, то есть рядом с этапом 9 и «темами слайдов». Частично заменяет загрузку своих фонов из CR выше.

## Решения и предпочтения
- Дизайну нейросетей не доверяем; целевой вывод — JPEG, собранный из шаблона.
- Медиафайлы проповедник присылает отдельно, подписывая номером слайда.
- Telegraph для оператора отвергнут; сжатые данные в ссылке — тоже (лимит Telegram 4096 символов). Google Диск для настроек отвергнут (нужен ключ API).
- Код Виталию присылать целиком, не фрагментами. Тексты для пользователей — естественный русский, без канцелярита.
- Вход обязателен (этап 8): «Продолжить без входа» и файлы убраны, старые черновики из браузера не переносятся.
- Облако: Firebase (вход Google + Firestore, без карты) + GitHub Pages; картинки потом через Диск церкви. Роли админ / редактор / проповедник, пространства для разных церквей. Подробно — `docs/PLAN.md`.
- Права (этап 4, с правками 7.3 и 8): админ всей формы (`admins/{почта}`, пишет только служебный скрипт) видит все пространства и может в них всё; участников добавляет и меняет только он; роль `admin` у участника — просто редактор. Автор (`preacher`) правит только свои проповеди и только пока они не «У редактора», сам ставит лишь «Черновик» и «Готов к вёрстке», удаляет только свой черновик; «У редактора» — редактор. Админ не может снять админа с себя. Новые пространства заводит только служебный скрипт — чтобы посторонние не заняли место в бесплатной базе (открыть для других церквей — потом, одним правилом). Ссылку для оператора делает тот, кто может править проповедь; открыть её может кто угодно по ключу.
- Плотность текста как в Canva — основная для всех текстов (подтвердить на проекторе).
- Заметка оператору остаётся отдельным блоком — узкий жёлтый мини-слайд в ленте.
