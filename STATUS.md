# Crosspect — состояние проекта

Обновлено: 11 ноября 2026. Код формы: [`index.html`](index.html), [`css/`](css), [`js/`](js). Устройство кода: [`ARCHITECTURE.md`](ARCHITECTURE.md). Правила для Claude: [`CLAUDE.md`](CLAUDE.md).

## Что это

Crosspect — браузерная форма церкви «Слово веры» (Познань). Проповедник собирает конспект проповеди из блоков в одном формате, вместо Telegram, Word, Google Диска и PPTX. Виталий по нему делает слайды (Canva / Holyrics), часть слайдов форма собирает сама в JPEG. Оператор на служении смотрит конспект с телефона.

Название: Cross (крест) + -spect («смотреть»: inspect, aspect). По-русски созвучно со словом «конспект».

Решено: форма станет **обязательной** для всех проповедников. Серии проповедей пока не рассматриваем.

## Как сейчас работать

- Форма открывается по ссылке `https://crosspect-app.github.io/crosspect/`. Версия всегда свежая; ничего скачивать и обновлять не нужно.
- «Сохранить» (Ctrl+S) скачивает файл `.json` с проповедью — его можно переслать. «Открыть» загружает `.json` или **старый HTML-файл проповеди**, сохранённый прежней формой.
- Черновик сам сохраняется в браузере (localStorage). У ссылки на Pages свой черновик: то, что было в старой форме на компьютере, туда не перейдёт. Старую проповедь нужно один раз открыть через «Открыть» и сохранить.
- Проповедник прислал исправленный файл: «Открыть» → выбрать файл. Отметки «готово», которые ставил Виталий, в чужом файле не сохраняются.
- Интернет нужен для шрифтов, настроек и текстов Библии.
- Основной браузер — Chrome. Выгрузку слайдов делает только Виталий.
- Выгрузка JPEG работает только по ссылке на сайт (или с локального сервера): со страницы, открытой двойным щелчком из папки, браузер не даёт прочитать стили слайда.

## Что умеет форма

### Шапка и режимы
- Дата (по умолчанию ближайшее воскресенье), проповедник из списка (из настроек) или «Другой — ввести вручную».
- Режимы «Редактор» и «Просмотр» (для оператора). Тёмная и светлая тема по системе. Интерфейс на Unbounded.

### Блоки
Окно «Что добавить?»: сверху широкий «Текст проповеди» и узкая «Заметка оператору», ниже парами: Место Писания и Свободный слайд, Тезис и Цитата, Картинка и Видео.

1. **Текст проповеди** — на экран не идёт; галочка «Здесь вывести заставку».
2. **Заметка оператору** — в редакторе жёлтая, в просмотре и PDF яркая плашка заглавными жирным; видна даже в режиме «Только слайды».
3. **Место Писания** — один слайд, части в отдельных карточках: места Писания (любые переводы), текст (переключатель «Заглавными буквами», по умолчанию включён), «Линия» (тонкая черта во всю ширину текста). Выбор: перевод → книга → глава → стихи (кнопки, Shift+клик, поле «1-3, 5», «Вся глава», «Сбросить»). Текст стиха можно править, ↺ возвращает исходный. «Продолжить на новом слайде» переносит и настройку «Показывать перевод на слайде».
4. **Тезис** — из нескольких частей: текст и «Линия». У каждой текстовой части своё выравнивание по горизонтали, размер (70–130%) и «Заглавными буквами». Выравнивание по вертикали (верх / центр / низ) одно на весь слайд. Списки: «- » → точка, «1. » → нумерация с автопродолжением; Enter продолжает список, Enter на пустом пункте — выход.
5. **Цитата** — текст + автор; «Заглавными буквами» (по умолчанию выкл.); размер 70–110%.
6. **Картинка** («Найди сам» / «Пришлю отдельно»), **Видео** («Ссылка» / «Пришлю отдельно», тайминг, комментарий), **Свободный слайд**.

Кнопки блока: скопировать название слайда, скачать JPEG (Писание, тезис, цитата), отметка «готово», свернуть, в самый верх / выше / ниже / в самый низ, дублировать, удалить. Клик по заголовку блока — свернуть / развернуть.

### Названия слайдов (имена файлов для Holyrics)
- Писание — само, по первому месту на слайде: `[3] 1 КОР. 12_7-9,12` (синодальные сокращения, «:» → «_»).
- Цитата — само: `[4] цитата Оливер КАН` (источник после запятой отбрасывается).
- Тезис, картинка, видео, свободный — поле «Название слайда», номер `[N]` зашит и не стирается. Название тезиса по умолчанию собирается из первых слов текста (до 5 слов, целыми словами, в пределах лимита, без «и/не/к…» в конце), пока его не правили руками.
- Символы `\ / : * ? " < > |` не вводятся. Лимит 35 символов, обязательность — в настройках.
- Без обязательного названия нельзя перейти в «Просмотр», выгрузить и собрать PDF; при сохранении — выбор «Дописать названия» или «Сохранить без них».
- Подсказки: тезис «Сформируется само из первых слов текста», картинка «Фото Десмонд Досс», видео «История Николаса Винтона», свободный «Значения слова АГАПЕ».
- При добавлении тезиса и цитаты курсор сразу в тексте (на компьютере).

### Оформление текста
Панель: **Ж**, **К**, Ч, маркер (#ffde59 на слайде), «АА» (все прописные для выделенного куска), списки «•» и «1.» (в тезисе), «Убрать оформление». Несколько пробелов подряд сохраняются на слайде. Мягкие переносы при вставке убираются. Греческий и иврит везде выводятся шрифтом Inter / Noto Sans Hebrew жирным и не переводятся в заглавные (чтобы не терялись ударения).

### Отметка «готово» и сворачивание
- ✓ в блоке — отметка «готово» (зелёная подсветка). Ставится сама при выгрузке, если её ещё нет; снимается вручную.
- Меню «⋯»: свернуть / развернуть все, свернуть готовые (неготовые раскрываются), свернуть неготовые (готовые раскрываются), свернуть текст и заметки. В «Просмотре» сворачивание недоступно.

### Выгрузка
- **JPEG 1920×1080** одного слайда — обычный файл с названием слайда.
- **«Скачать все слайды» / «Скачать неотмеченные слайды»** — ZIP-архив с папкой «2026-11-08 Название». Картинки, видео и свободные слайды не собираются: их Виталий делает в Canva, название копирует кнопкой.
- **PDF для оператора** — «⋯ → PDF для оператора», в окне печати Chrome «Сохранить как PDF». Узкие страницы 80×170 мм под телефон. Внутри: номера и названия слайдов, текст Писания, тезисы и цитаты, текст проповеди тонким серым, заметки жёлтыми плашками. Подсказки для редактора (найти, пришлют, описания, ссылки) не попадают. Слайд не разрывается между страницами.

### Настройки
- «⋯ → Настройки слайдов»: макет слайда со штрихованной областью текста; поля (по умолчанию 60 px от края панели со всех сторон); обязательность и длина названий; **размер стихов Писания** (общий, 100% = 48 px, 50–200%); диапазоны размеров тезиса и цитаты. Своё значение действует в этом браузере; «Скопировать для config.json» — чтобы сделать общим.
- **Временно, для теста:** свёрнутый раздел «Шрифт как в Canva» — вариант 1 без изменений, 2 только стихи, 3 весь текст: толщина 325 вместо 400, буквы плотнее (−0,04 em), строки 1,05 вместо 1,25. Для совпадения с Canva — Писание 110%. После тестов на проекторе выбрать вариант, зашить в форму, раздел убрать.
- «Лимиты»: до какого % уменьшать Писание (80%), тезис 220 и цитата 300 символов — превышение подсвечивается жёлтым.
- «Источник настроек»: ссылка на `config.json`, «Проверить и применить», «По умолчанию».

## Слайды (предпросмотр = итоговый JPEG)
- Кадр 1920×1080. Слои: чёрная основа; кремовая рамка #ecdfcf с зерном (отступ 14, радиус 34); панель (отступ 44, радиус 8) с градиентом «Ember».
- Текст #ecdfcf, Unbounded Regular; ссылка и номера стихов Bold. Межстрочный интервал 1,25.
- Писание: базовый размер 48 px (общая настройка), ссылка 1,2083 em, подпись перевода «* Синодальный перевод» — 90% от размера стихов, внизу. Длинное место уменьшается до лимита.
- Тезис 50,4 px (100%), цитата 51,48 px (100%), автор 52 px в правом нижнем углу (имя обычным, фамилия жирным, заглавными; источник мелко второй строкой).
- Переносы: короткие слова и предлоги приклеиваются к следующему, же/ли/бы к предыдущему, одно слово на последней строке не остаётся.

## Переводы Библии
- Список в `data/config.json` (23 перевода): русский (Синодальный, НРП, Кулаков, СРП РБО — НЗ, Десницкий, Библейская лига, Кассиан — НЗ), украинский (Огієнко, Турконяк, Хоменко, Сучасною мовою, НПУ — НЗ), польский (BW, UBG, BG, NBG, EIB, Słowo Życia — NT, NPD — NT), английский (NIV, KJV, NKJV, ESV). Встроенный запасной список — 22.
- «Свой перевод» встроен в форму: всё вводится вручную, поля без подсказок; при выборе всё очищается.
- Источник текстов — Beblia (`raw.githubusercontent.com/Beblia/Holy-Bible-XML-Format`), свои файлы — `data/bibles/`. Форматы Beblia и Zefania.
- Десницкий — из модуля MyBible (48 книг). Условия автора: некоммерческое использование с указанием авторства, текст не менять → в инструкции для проповедников сказать, что формулировки перевода не переписывают.
- СРП ВЗ — только у Виталия (Zefania из Holyrics), публично не выкладываем.
- Убраны: Восточный перевод, Куліш і Пулюй, RST 1900.
- Не проверено: польские и украинские названия книг; нужна ли запятая в польской ссылке («Jana 3,16»). У Кулакова в Псалмах надписание склеено с первым стихом.

## Известные проблемы и ограничения
- Отметки «готово» хранятся в файле и черновике Виталия; в исправленном файле от проповедника их нет.
- Старые HTML-файлы проповедей открываются, но сохраняются уже как `.json`.
- Выгрузка JPEG требует интернета (шрифты встраиваются в картинку).
- Как PDF для оператора открывается в Telegram на телефоне — не проверено.
- Поля, размер Писания, режим шрифта пока не записаны в `config.json` — действуют только в браузере Виталия.
- В «Просмотре» кнопка копирования в карточке копирует текст слайда, а не название (в редакторе — название). Решить, нужно ли иначе.

## Анализ того, как присылают сейчас
Образцы: Telegram-текст, несколько docx и Google Документ, список ссылок сообщением, Telegram Евгения Шоды (каждое сообщение ≈ слайд). Ссылки пишут по-разному: «Иак.1:2-4», «3Цар 18:36-38», «1 Коринфянам, 1 глава, 10–12 стихи», «Осия 11:1-4/8-9», «1Кор 13,4», «Марка» без «От». Часто приводят свой текст стиха — он главнее ссылки. Бывают фото людей с историями, греческие слова, двуязычные слайды, просьбы оператору.

## Отложено (после облака)
- **Быстрый ввод ссылки**: вставить «Иак 1:2-4» или целый список → форма сама создаёт слайды (словарь сокращений из анализа выше).
- **Работа с готовым текстом**: вставить весь текст проповеди, найденные ссылки подсвечиваются с кнопкой «Сделать слайдом».
- Картинки через Google Диск церкви; фото с подписью и цитата с портретом; блок «Слово» для греческих/еврейских слов; темы слайдов (Ember / Dusk / новые).
- Помощник на церковном ПК для Holyrics; Telegram-бот.
- Короткая инструкция для проповедников и пример заполненной проповеди.

## Решения и предпочтения
- Дизайну нейросетей не доверяем; целевой вывод — JPEG, собранный из шаблона.
- Медиафайлы проповедник присылает отдельно, подписывая номером слайда.
- Telegraph для оператора отвергнут; сжатые данные в ссылке — тоже (лимит Telegram 4096 символов). Google Диск для настроек отвергнут (нужен ключ API).
- Код Виталию присылать целиком, не фрагментами. Тексты для пользователей — естественный русский, без канцелярита.
- Облако: Firebase (вход Google + Firestore, без карты) + GitHub Pages; картинки потом через Диск церкви. Роли админ / редактор / проповедник, пространства для разных церквей. Подробно — `docs/PLAN.md`.
- Плотность текста как в Canva — основная для всех текстов (подтвердить на проекторе).
- Заметка оператору остаётся отдельным блоком — узкий жёлтый мини-слайд в ленте.
