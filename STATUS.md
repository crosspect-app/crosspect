# Crosspect — состояние проекта

Обновлено: 18 ноября 2026 (этап 10.5.4). Код формы: [`index.html`](index.html), [`css/`](css), [`js/`](js). Устройство кода: [`ARCHITECTURE.md`](ARCHITECTURE.md). Правила для Claude: [`CLAUDE.md`](CLAUDE.md). Подробности — в [`docs/`](docs) (карта ниже).

## Что это

Crosspect — браузерная форма церкви «Слово веры» (Познань). Проповедник собирает конспект проповеди из блоков в одном формате, вместо Telegram, Word, Google Диска и PPTX. Виталий по нему делает слайды (Canva / Holyrics), часть слайдов форма собирает сама в JPEG. Оператор на служении смотрит конспект с телефона.

Решено: форма станет **обязательной** для всех проповедников.

## Как сейчас работать

- Форма открывается по ссылке `https://crosspect.app`; старый адрес `crosspect-app.github.io/crosspect` перенаправляет на него. Версия всегда свежая; ничего скачивать и обновлять не нужно.
- **Вход.** Без входа форма не работает (этап 8): сначала «Войти через Google». Пустят того, кого добавили в пространство (автором или редактором), и админа. Ссылка на проповедь (`#s=<id>&sp=<пространство>`) после входа открывает эту проповедь, даже если человек был в другом пространстве.
- **Пространства.** Админ всей формы — церковная почта Виталия (swpoznan.media@gmail.com, запись в базе `admins/…`): видит все пространства, в каждом может всё. Редактор и автор видят только те пространства, куда их добавили. Название пространства в шапке главной — список пространств (у каждого свои конспекты, люди, серии, настройки слайдов), под чертой — **«Настроить пространства»** (админ и редактор).
- **Окно «Пространства»** (этап 10.1.2): слева пространства, справа «Люди» (почта, Telegram, роль Редактор / Автор / Оператор, последний вход; оператор в форму не входит), «Серии проповедей» (удалить можно неиспользуемую), «Общее» (правит админ; «Удалить пространство» — только пустое). Авторы в «О проповеди» — роль «Автор»; «В Telegram» — все люди с Telegram.
- **Облако.** Проповеди лежат в Firestore. Конспект открывается для просмотра (поля серые); править — **«Редактировать»** (поля светлеют, с жёлтой рамкой), остальные видят «Сейчас правит Иван (с 15:20)» и живое обновление. Правки уходят в облако сами (раз в 30 секунд), Ctrl+S — сразу; закончили — **«Готово»**. Готов конспект — статус **«Готов к вёрстке»**. Ошиблись — **↶ ↷** или Ctrl+Z / Ctrl+Y.
- Файлы: «⋯ → Экспорт» (JPEG, PowerPoint, PDF для оператора) и «⋯ → Поделиться» (ссылка для оператора, PDF).
- Интернет нужен для самой формы, настроек и облака. Шрифты и переводы Библии — свои, лежат в репозитории (`fonts/`, `data/bibles/`).
- Основной браузер — Chrome; с телефона (Safari) — список, просмотр и правка «Текста к слайду». Выгрузку слайдов делает только Виталий.
